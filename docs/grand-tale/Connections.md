# Connections

The Connections page is a hub for player relationships.

## Sections

- **Status:** set your own status message.
- **Added Players**
- **Favourites**
- **Notes**
- **Blocked Players**
- **Recent Players**
- **Parties:** group finder.
- **Communities**
- **Clans**

## Previous Names

An account's previous name is kept for 30 days and shown in the player lists.
