# Atlas

Tracks logs for bounty drops, boss drops, treasure drops, and similar events.

Possible achievement: earn at least one of every item in a category.

## Sections

- World Map
- Item Codex
- Bestiary
  - Kill count per monster
  - Lore per monster
  - Loot table
- Soundtracks / Lorebooks / Cutscenes
  - Single repository for all the game's lore books
  - Diablo 3-style audio narrations
  - Unlocked as pages / chapters
