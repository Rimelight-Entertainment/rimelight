# Orders (Heartbringer)

Orders are special abilities that every pawn can perform to command its movement and attacks. Only one Order can be in effect at a time, so issuing a new Order overrides the previous one.

## List of Orders

- [Move](Move-Heartbringer.md)
- [Attack Move](Attack-Move-Heartbringer.md)
- [Attack](Attack-Heartbringer.md)
- Hold Position
- Stop
