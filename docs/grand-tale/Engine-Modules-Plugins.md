# Engine, Modules, and Plugins

Grand Tale is developed with Unreal Engine 5 and is kept up to date with the latest engine release.

## Modules

The source code is split into two modules:

- **RimelightGame:** the Game module.
- **RimelightEditor:** the Editor module.

## Plugins

Grand Tale uses many built-in Unreal Engine plugins. Plugins that are enabled by default but not needed have been disabled to reduce package size.

It also uses a first-party plugin, RimelightShared (see [RimelightShared](RimelightShared.md)).
