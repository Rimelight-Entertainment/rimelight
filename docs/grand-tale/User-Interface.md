# User Interface

## Common UI

Grand Tale uses the [Common UI Plugin](https://dev.epicgames.com/documentation/unreal-engine/common-ui-plugin-for-advanced-user-interfaces-in-unreal-engine) by Epic Games.

Classes should always inherit from their Common UI variants, and all widgets should use them too.

## Components

- Chat
- Window
- Prompt
- Tooltip
- Notifier
- Meter
- Wheel
