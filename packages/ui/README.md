# @rimelight/ui

The core UI library for Rimelight projects.

## Features

- Astro components
- Design system configurations
- Domain-specific utilities
- Optimized for performance and accessibility

## Installation

```bash
pnpm add @rimelight/ui
```

## Usage

```astro
---
import { YoutubeEmbed } from '@rimelight/ui/components/embeds';
---

<YoutubeEmbed id="..." />
```
