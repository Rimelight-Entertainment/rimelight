Rimelight UI supports a highly flexible color palette system, supporting both automatically generated light/dark modes and explicit bucket overrides.

## Standard Color Scale

The color scale uses OKLCH color spaces for perceptual lightness matching.

- **Primary**: Brand accent color.
- **Secondary**: Secondary brand accent color.
- **Success / Info / Warning / Error**: Standard utility colors.
- **Neutral**: Fully responsive background, text, and border scale.
