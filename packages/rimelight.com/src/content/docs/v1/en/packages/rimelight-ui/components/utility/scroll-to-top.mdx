The Scroll To Top component renders a floating action button that fades in once the user scrolls past a specified vertical threshold. Clicking the button smoothly scrolls the page back to the top.

## Usage

How to use the Scroll To Top component in its simplest form.

<ComponentShowcase>
  <div class="h-32 flex items-center justify-center text-muted-foreground italic">
    Scroll down the page to see the button appear in the bottom-right corner.
  </div>
  <RLAScrollToTop threshold={50} />

  <div slot="code-astro">
    ```astro
    ---
    import RLAScrollToTop from "@rimelight/ui/components/astro/RLAScrollToTop.astro";
    ---

    <!-- Floats in the bottom-right corner of the page -->
    <RLAScrollToTop />
    ```

  </div>
</ComponentShowcase>

## Examples

### Scroll Progress Ring

Use the `showProgress` prop to display a radial gauge around the button representing the current page scroll percentage.

<ComponentShowcase>
  <div class="h-32 flex items-center justify-center text-muted-foreground italic">
    Scroll down to see the progress ring fill up.
  </div>
  <RLAScrollToTop threshold={50} showProgress={true} color="success" />

  <div slot="code-astro">
    ```astro
    ---
    import RLAScrollToTop from "@rimelight/ui/components/astro/RLAScrollToTop.astro";
    ---

    <RLAScrollToTop showProgress={true} color="success" />
    ```

  </div>
</ComponentShowcase>
