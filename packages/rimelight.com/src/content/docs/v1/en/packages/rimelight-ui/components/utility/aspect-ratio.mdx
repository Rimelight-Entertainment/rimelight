The Aspect Ratio component enforces a desired width-to-height ratio for its children (such as images, maps, or videos) while remaining responsive.

## Usage

How to use the Aspect Ratio component in its simplest form.

<ComponentShowcase>
  <div class="w-80 max-w-full">
    <RLAAspectRatio ratio={16 / 9}>
      <div class="bg-neutral-100 dark:bg-neutral-800 text-muted-foreground w-full h-full flex items-center justify-center rounded-lg border border-border">16:9 Content</div>
    </RLAAspectRatio>
  </div>

  <div slot="code-astro">
    ```astro
    ---
    import RLAAspectRatio from "@rimelight/ui/components/astro/RLAAspectRatio.astro";
    ---

    <div class="w-80 max-w-full">
      <RLAAspectRatio ratio={16 / 9}>
        <div class="bg-neutral-100 dark:bg-neutral-800 text-muted-foreground w-full h-full flex items-center justify-center rounded-lg border border-border">
          16:9 Content
        </div>
      </RLAAspectRatio>
    </div>
    ```

  </div>
</ComponentShowcase>

## Examples

### Square Ratio

Use a ratio of `1` (or `1 / 1`) to constrain content to a perfect square.

<ComponentShowcase>
  <div class="w-48 max-w-full">
    <RLAAspectRatio ratio={1}>
      <div class="bg-neutral-100 dark:bg-neutral-800 text-muted-foreground w-full h-full flex items-center justify-center rounded-lg border border-border">1:1 Content</div>
    </RLAAspectRatio>
  </div>

  <div slot="code-astro">
    ```astro
    ---
    import RLAAspectRatio from "@rimelight/ui/components/astro/RLAAspectRatio.astro";
    ---

    <div class="w-48 max-w-full">
      <RLAAspectRatio ratio={1}>

          1:1 Content
        </div>
      </RLAAspectRatio>
    </div>
    ```

  </div>
</ComponentShowcase>
