The `FieldGroup` component allows you to attach icons, labels, or buttons before or after an input field in a unified border and background wrap.

## Usage

<ComponentShowcase>
  <RLAFieldGroup prepend="$">
    <input type="text" class="bg-transparent border-0 outline-none w-full px-2" placeholder="0.00" />
  </RLAFieldGroup>

  <div slot="code-astro">
    ```astro
    ---
    import RLAFieldGroup from "@rimelight/ui/components/astro/RLAFieldGroup.astro";
    ---

    <RLAFieldGroup prepend="$">
      <input type="text" class="bg-transparent border-none outline-none w-full px-2" placeholder="0.00" />
    </RLAFieldGroup>
    ```

  </div>
</ComponentShowcase>

## Examples

### Prepend and Append

You can use both `prepend` and `append` to wrap a control from both sides.

<ComponentShowcase>
  <RLAFieldGroup prepend="https://" append=".com">
    <input type="text" class="bg-transparent border-0 outline-none w-full px-2" placeholder="mysite" />
  </RLAFieldGroup>

  <div slot="code-astro">
    ```astro
    <RLAFieldGroup prepend="https://" append=".com">
      <input type="text" class="bg-transparent border-none outline-none w-full px-2" placeholder="mysite" />
    </RLAFieldGroup>
    ```
  </div>
</ComponentShowcase>
