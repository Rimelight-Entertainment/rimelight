The Gallery component is a flexible container designed to group and display media files, project cards, or portfolios in a consistent layout.

## Usage

Use the Gallery component as a container for your grid items.

<ComponentShowcase>

## Examples

### Custom Masonry/Ratio layout

Since the Gallery component accepts normal grid and size utility classes, you can style the layout to support different aspect ratios.

<ComponentShowcase>
  <RLAGallery class="grid grid-cols-1 sm:grid-cols-2 gap-4">
    <div class="bg-card p-4 border rounded">

    <div class="bg-card p-4 border rounded">
      <h3 class="font-bold text-lg">Project Beta</h3>
