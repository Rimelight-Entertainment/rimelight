## Usage

How to use the Input component in its simplest form.

<ComponentShowcase>
  <RLAInput placeholder="Type here..." />

  <div slot="code-astro">
    ```astro
    ---
    import RLAInput from "@rimelight/ui/components/input/RLAInput.astro";
    ---

    <RLAInput placeholder="Type here..." />
    ```

  </div>
</ComponentShowcase>

## Examples

### Icons

Use `leadingIcon` and `trailingIcon` props to display icons inside the input.

<ComponentShowcase>
  <div class="flex flex-col gap-4 w-full max-w-xs">
    <RLAInput placeholder="Search..." leadingIcon="i-lucide-search" />
    <RLAInput placeholder="Password" type="password" trailingIcon="i-lucide-lock" />
  </div>

  <div slot="code-astro">
    ```astro
    ---
    import RLAInput from "@rimelight/ui/components/input/RLAInput.astro";
    ---

    <RLAInput placeholder="Search..." leadingIcon="i-lucide-search" />
    <RLAInput placeholder="Password" type="password" trailingIcon="i-lucide-lock" />
    ```

  </div>
</ComponentShowcase>

### Error State

Use the `error` prop to apply validation styling.

<ComponentShowcase>
  <RLAInput placeholder="Incorrect value" error />

  <div slot="code-astro">
    ```astro
    ---
    import RLAInput from "@rimelight/ui/components/input/RLAInput.astro";
    ---

    <RLAInput placeholder="Incorrect value" error />
    ```

  </div>
</ComponentShowcase>
