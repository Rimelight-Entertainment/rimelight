The `Separator` component is used to separate content zones. It supports horizontal and vertical orientations, dashed/dotted styles, and centering of badges, icons, or text.

## Usage

<ComponentShowcase>
  <div class="w-full">
    <p class="text-sm">Above separator</p>
    <RLASeparator />
    <p class="text-sm">Below separator</p>
  </div>

  <div slot="code-astro">
    ```astro
    ---
    import RLASeparator from "@rimelight/ui/components/astro/RLASeparator.astro";
    ---

    <div>
      <p>Above separator</p>
      <RLASeparator />
      <p>Below separator</p>
    </div>
    ```

  </div>
</ComponentShowcase>

## Examples

### With Label

You can add a text label in the middle of the separator.

<ComponentShowcase>
  <div class="w-full">
    <RLASeparator label="OR" />
  </div>

  <div slot="code-astro">
    ```astro
    <RLASeparator label="OR" />
    ```
  </div>
</ComponentShowcase>

### With Icon or Avatar

You can center an icon or an avatar inside the separator.

<ComponentShowcase>
  <div class="w-full flex flex-col gap-4">
    <RLASeparator icon="i-lucide-star" />
    <RLASeparator avatar="https://i.pravatar.cc/150?img=3" />
  </div>

  <div slot="code-astro">
    ```astro
    <RLASeparator icon="i-lucide-star" />
    <RLASeparator avatar="https://i.pravatar.cc/150?img=3" />
    ```
  </div>
</ComponentShowcase>

### Types & Positions

Adjust the line border type (`solid`, `dashed`, `dotted`) and the label position (`start`, `center`, `end`).

<ComponentShowcase>
  <div class="w-full flex flex-col gap-4">
    <RLASeparator label="Start Details" position="start" type="dashed" />
    <RLASeparator label="End Section" position="end" type="dotted" />
  </div>

  <div slot="code-astro">
    ```astro
    <RLASeparator label="Start Details" position="start" type="dashed" />
    <RLASeparator label="End Section" position="end" type="dotted" />
    ```
  </div>
</ComponentShowcase>

### Vertical

Use `orientation="vertical"` to split horizontal blocks. Make sure the container has a defined height.

<ComponentShowcase>
  <div class="flex h-5 items-center gap-4 text-sm">
    <div>Blog</div>
    <RLASeparator orientation="vertical" />
    <div>Docs</div>
    <RLASeparator orientation="vertical" />
    <div>Source</div>
  </div>

  <div slot="code-astro">
    ```astro
    <div class="flex h-5 items-center gap-4">
      <div>Blog</div>
      <RLASeparator orientation="vertical" />
      <div>Docs</div>
      <RLASeparator orientation="vertical" />
      <div>Source</div>
    </div>
    ```
  </div>
</ComponentShowcase>
