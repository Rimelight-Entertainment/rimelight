The `LinkGroup` component displays a header title followed by a list of links. It is commonly used to structure links in footer grids, navigation sidebars, or directories.

## Usage

<ComponentShowcase>
  <RLALinkGroup
    title="Resources"
    links={[
      { label: "Documentation", href: "/docs" },
      { label: "GitHub Repository", href: "https://github.com" },
      { label: "Community Chat", href: "https://discord.gg" }
    ]}
  />

  <div slot="code-astro">
    ```astro
    ---
    import RLALinkGroup from "@rimelight/ui/components/astro/RLALinkGroup.astro";

    const links = [
      { label: "Documentation", href: "/docs" },
      { label: "GitHub Repository", href: "https://github.com" },
      { label: "Community Chat", href: "https://discord.gg" }
    ];
    ---

    <RLALinkGroup title="Resources" links={links} />
    ```

  </div>
</ComponentShowcase>

## Examples

### Title with Icon and Link

You can configure the group title to have icons or be a link itself.

<ComponentShowcase>
  <RLALinkGroup
    title={{
      label: "Our Products",
      href: "/products",
      leadingIcon: "i-lucide-package"
    }}
    links={[
      { label: "Rimelight UI", href: "/products/ui" },
      { label: "Vite Plus", href: "/products/vite-plus" }
    ]}
  />

  <div slot="code-astro">
    ```astro
    <RLALinkGroup
      title={{
        label: "Our Products",
        href: "/products",
        leadingIcon: "i-lucide-package"
      }}
      links={[
        { label: "Rimelight UI", href: "/products/ui" },
        { label: "Vite Plus", href: "/products/vite-plus" }
      ]}
    />
    ```
  </div>
</ComponentShowcase>
