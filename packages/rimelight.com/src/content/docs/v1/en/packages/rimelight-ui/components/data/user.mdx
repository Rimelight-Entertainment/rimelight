The User component is a wrapper container designed to display user profile details, integrating an avatar alongside user meta information.

## Usage

Place user details (e.g. `RLAAvatar` and name text) inside the default slot of the User component.

<ComponentShowcase>
  <RLAUser class="flex items-center gap-3">
    <RLAAvatar src="https://i.pravatar.cc/150?img=3" alt="Jane Doe" size="md" />
    <div class="flex flex-col">
      <span class="text-sm font-semibold text-foreground">Jane Doe</span>
      <span class="text-xs text-muted-foreground">Software Engineer</span>
    </div>
  </RLAUser>

  <div slot="code-astro">
