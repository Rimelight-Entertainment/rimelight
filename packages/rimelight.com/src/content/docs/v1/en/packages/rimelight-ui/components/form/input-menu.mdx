A dropdown menu input with built-in search/filter functionality for selecting items.

## Usage

How to use the Input Menu component in its simplest form.

<ComponentShowcase>
  <RLAInputMenu items={["Apple", "Banana", "Cherry"]} placeholder="Select fruit..." />

  <div slot="code-astro">
    ```astro
    ---
    import RLAInputMenu from "@rimelight/ui/components/input-menu/RLAInputMenu.astro";
    ---

    <RLAInputMenu items={["Apple", "Banana", "Cherry"]} placeholder="Select fruit..." />
    ```

  </div>
</ComponentShowcase>

## Examples

### With Label

Add a label to describe the dropdown field.

<ComponentShowcase>
  <RLAInputMenu
    label="Choose your favorite fruit"
    items={["Apple", "Banana", "Cherry"]}
    placeholder="Select fruit..."
  />

  <div slot="code-astro">
    ```astro
    ---
    import RLAInputMenu from "@rimelight/ui/components/input-menu/RLAInputMenu.astro";
    ---

    <RLAInputMenu
      label="Choose your favorite fruit"
      items={["Apple", "Banana", "Cherry"]}
      placeholder="Select fruit..."
    />
    ```

  </div>
</ComponentShowcase>

Use the `disabled` prop to prevent interaction.
