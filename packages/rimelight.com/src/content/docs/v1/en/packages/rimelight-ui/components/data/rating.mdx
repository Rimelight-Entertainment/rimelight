The Rating component is a wrapper used to group star icons or scoring indicators for products and reviews.

## Usage

Place rating icons inside the default slot of the Rating component.

<ComponentShowcase>
  <RLARating class="flex gap-1 text-amber-500">
    <span class="i-lucide-star size-5 fill-current" />
    <span class="i-lucide-star size-5 fill-current" />
    <span class="i-lucide-star size-5 fill-current" />
    <span class="i-lucide-star size-5 fill-current" />
    <span class="i-lucide-star size-5 text-muted-foreground" />
  </RLARating>

  <div slot="code-astro">
    ```astro
    ---
    import RLARating from "@rimelight/ui/components/astro/RLARating.astro";
    ---

    <RLARating class="flex gap-1 text-amber-500">
      <span class="i-lucide-star size-5 fill-current" />
      <span class="i-lucide-star size-5 fill-current" />
      <span class="i-lucide-star size-5 fill-current" />
      <span class="i-lucide-star size-5 fill-current" />
      <span class="i-lucide-star size-5 text-muted-foreground" />
    </RLARating>
    ```

  </div>
</ComponentShowcase>
