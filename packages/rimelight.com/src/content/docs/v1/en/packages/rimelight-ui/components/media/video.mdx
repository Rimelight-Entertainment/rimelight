The Video component renders a YouTube video player that lazy-loads its iframe. It fetches the high-quality video thumbnail at build time and only instantiates the iframe when the user clicks the play button, saving network bandwidth.

## Usage

How to use the Video component in its simplest form.

<ComponentShowcase>
  <div class="max-w-xl">
    <RLAVideo src="https://www.youtube.com/watch?v=dQw4w9WgXcQ" title="Rick Astley - Never Gonna Give You Up" />
  </div>

  <div slot="code-astro">
    ```astro
    ---
    import RLAVideo from "@rimelight/ui/components/astro/RLAVideo.astro";
    ---

    <div class="max-w-xl">
      <RLAVideo src="https://www.youtube.com/watch?v=dQw4w9WgXcQ" title="Rick Astley - Never Gonna Give You Up" />
    </div>
    ```

  </div>
</ComponentShowcase>
