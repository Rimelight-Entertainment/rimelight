## Examples

### Items

Use the `items` prop as an array of objects with options like `date`, `title`, `description`, `icon`, `avatar`, `value`, `slot`, `class`, and `ui`.

<ComponentShowcase>
  <RLATimeline defaultValue={2} items={sampleItems} class="w-96" />

  <div slot="code-astro">
    ```astro
    <RLATimeline defaultValue={2} items={items} class="w-96" />
    ```
  </div>
</ComponentShowcase>

### Color

Use the `color` prop to change the color of the active items in a Timeline.

<ComponentShowcase>
  <div class="flex flex-col gap-6 w-96">
    <div>
      <p class="text-xs font-semibold text-muted-foreground mb-2">Primary (Default)</p>
      <RLATimeline color="primary" defaultValue={2} items={sampleItems} />
    </div>
    <div>
      <p class="text-xs font-semibold text-muted-foreground mb-2">Neutral</p>
      <RLATimeline color="neutral" defaultValue={2} items={sampleItems} />
    </div>
  </div>

  <div slot="code-astro">
    ```astro
    <!-- Primary (Default) -->
    <RLATimeline color="primary" defaultValue={2} items={items} class="w-96" />

    <!-- Neutral -->
    <RLATimeline color="neutral" defaultValue={2} items={items} class="w-96" />
    ```

  </div>
</ComponentShowcase>

### Size

Use the `size` prop to change the size of the Timeline.

<ComponentShowcase>
  <RLATimeline size="xs" defaultValue={2} items={sampleItems} class="w-96" />

  <div slot="code-astro">
    ```astro
    <RLATimeline size="xs" defaultValue={2} items={items} class="w-96" />
    ```
  </div>
</ComponentShowcase>

### Orientation

Use the `orientation` prop to change the orientation of the Timeline. Defaults to `vertical`.

<ComponentShowcase>
  <RLATimeline orientation="horizontal" defaultValue={2} items={sampleItems} class="w-full" />

  <div slot="code-astro">
    ```astro
    <RLATimeline orientation="horizontal" defaultValue={2} items={items} class="w-full" />
    ```
  </div>
</ComponentShowcase>

### Reverse

Use the `reverse` prop to reverse the direction of the Timeline.

<ComponentShowcase>
  <RLATimeline reverse defaultValue={2} orientation="vertical" items={sampleItems} class="w-full" />

  <div slot="code-astro">
    ```astro
    <RLATimeline reverse defaultValue={2} orientation="vertical" items={items} class="w-full" />
    ```
  </div>
</ComponentShowcase>

Use the `ui` prop to create a Timeline with an alternating layout.

  </div>
</ComponentShowcase>
