## What are Skills?

Skills are structured knowledge files that give AI coding agents context about a library, framework, or codebase. Unlike MCP servers that provide real-time tool access, skills are loaded directly into the agent's context so it can reference them throughout the conversation.

Rimelight UI provides a **usage skill** that teaches AI agents how to build UIs with our dual-engine architecture.

## Usage

The Rimelight UI skill gives AI agents comprehensive knowledge about building with our library. It covers:

- **Dual-Engine Strategy:** When to use Astro (RLA) vs Vue (RLV) components.
- **Theming:** Branding with semantic colors and CSS variants.
- **Component Library:** Props, slots, and usage patterns for all native components.
- **UnoCSS Integration:** Proper use of atomic classes within the Rimelight ecosystem.

## Installation

### Skills CLI

The [`skills`](https://skills.sh) CLI is the easiest way to install the Rimelight UI skill.

```bash
npx skills add rimelight/ui
```

### Cursor

1. Open Cursor and go to **Settings** > **Skills**.
2. Click **Add skill** and enter the following URL:
   `https://github.com/rimelight/rimelight/tree/main/skills/ui`

### Claude Code

Add the skill using the CLI command:

```bash
claude skill add https://github.com/rimelight/rimelight/tree/main/skills/ui
```

## Usage in Chat

Once installed, you can invoke the skill by typing `/ui` in your agent's chat to get specialized assistance with Rimelight UI components and patterns.
