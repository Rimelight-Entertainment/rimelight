The Footer component wraps footer structures, supporting left, center, and right slot areas for copyright information, navigation links, and utilities.

## Usage

Use the Footer component to define the bottom section of your site or application.

<ComponentShowcase>
  <RLAFooter>
    <div slot="left">© 2026 Rimelight Entertainment</div>
    <div slot="center">All rights reserved</div>
    <div slot="right">v1.0.0</div>
  </RLAFooter>

  <div slot="code-astro">
    ```astro
    ---
    import RLAFooter from "@rimelight/ui/components/astro/RLAFooter.astro";
    ---

    <RLAFooter>
      <div slot="left">© 2026 Rimelight Entertainment</div>
      <div slot="center">All rights reserved</div>
      <div slot="right">v1.0.0</div>
    </RLAFooter>
    ```

  </div>
</ComponentShowcase>

## Examples

### Contain

Set the `contain` prop to limit the inner width of the footer container.

<ComponentShowcase>
  <RLAFooter contain>
    <div slot="left">© 2026 Rimelight</div>
    <div slot="right">Privacy Policy</div>
  </RLAFooter>

  <div slot="code-astro">
    ```astro
    ---
    import RLAFooter from "@rimelight/ui/components/astro/RLAFooter.astro";

    <RLAFooter contain>
      <div slot="left">© 2026 Rimelight</div>
      <div slot="right">Privacy Policy</div>
    </RLAFooter>
    ```

  </div>
</ComponentShowcase>
