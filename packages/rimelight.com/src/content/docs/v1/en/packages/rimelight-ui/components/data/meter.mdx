The Meter component is a wrapper used to represent scalar values or fractional values within a known range, such as disk usage or search relevance.

## Usage

Render the Meter component wrapping an HTML `<meter>` or custom markup inside the default slot.

<ComponentShowcase>
  <RLAMeter>
    <div class="flex flex-col gap-2 w-full max-w-sm">
      <div class="flex justify-between text-sm">
        <span>Storage space</span>
        <span class="font-semibold">70GB / 100GB</span>
      </div>
      <meter class="w-full h-3 rounded overflow-hidden" min="0" max="100" low="33" high="66" optimum="80" value="70"></meter>
    </div>
  </RLAMeter>

  <div slot="code-astro">
    ```astro
    ---
    import RLAMeter from "@rimelight/ui/components/astro/RLAMeter.astro";

    ```

  </div>
</ComponentShowcase>
