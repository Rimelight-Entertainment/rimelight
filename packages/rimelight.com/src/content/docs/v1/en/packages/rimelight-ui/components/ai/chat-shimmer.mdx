The ChatShimmer component renders animated skeletons to indicate that a response or action is loading/streaming.

## Usage

Use the ChatShimmer component to build custom skeleton loading states in your chat logs.

<ComponentShowcase>
  <RLAChatShimmer class="flex flex-col gap-2 w-full max-w-md animate-pulse">
    <div class="h-4 bg-muted rounded w-3/4"></div>
    <div class="h-4 bg-muted rounded w-1/2"></div>
  </RLAChatShimmer>

  <div slot="code-astro">
    ```astro
    ---
    import RLAChatShimmer from "@rimelight/ui/components/chat-shimmer/RLAChatShimmer.astro";
    ---

    <RLAChatShimmer class="flex flex-col gap-2 w-full max-w-md animate-pulse">
      <div class="h-4 bg-muted rounded w-3/4"></div>
      <div class="h-4 bg-muted rounded w-1/2"></div>
    </RLAChatShimmer>
    ```

  </div>
</ComponentShowcase>
