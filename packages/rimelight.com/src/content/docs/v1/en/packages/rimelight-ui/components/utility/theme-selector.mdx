The Theme Selector component renders an icon button that toggles the application between light and dark visual themes. It stores the user's preference in localStorage and also listens to a keyboard shortcut (`Meta + Alt + T`) to trigger toggling.

## Usage

How to use the Theme Selector component in its simplest form.
