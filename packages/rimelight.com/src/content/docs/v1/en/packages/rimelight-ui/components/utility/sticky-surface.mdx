The Sticky Surface component pins its contents vertically within a parent container once the page scrolls past its position.

## Usage

How to use the Sticky Surface component in its simplest form.

<ComponentShowcase>
  <div class="h-48 overflow-y-auto border border-border rounded-lg p-md relative bg-neutral-50 dark:bg-neutral-900">
    <div class="h-24 bg-neutral-200 dark:bg-neutral-800 p-sm rounded mb-md">Scrollable Header Content</div>
    <RLAStickySurface offsetTop={10} class="sticky">
      <div class="p-4 bg-primary text-primary-foreground font-bold rounded shadow-sm">I stick to the top!</div>
    </RLAStickySurface>
    <div class="h-64 bg-neutral-200 dark:bg-neutral-800 p-sm rounded mt-md">More scrollable contents to demonstrate stickiness...</div>
  </div>

  <div slot="code-astro">
    ```astro
    ---
    import RLAStickySurface from "@rimelight/ui/components/astro/RLAStickySurface.astro";
    ---

    <div class="relative">
      <RLAStickySurface offsetTop={10} class="sticky">
        <div class="p-4 bg-primary text-primary-foreground font-bold rounded shadow-sm">
          I stick to the top!
        </div>
      </RLAStickySurface>
    </div>
    ```

  </div>
</ComponentShowcase>
