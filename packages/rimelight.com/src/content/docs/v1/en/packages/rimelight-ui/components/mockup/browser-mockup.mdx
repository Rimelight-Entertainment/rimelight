The Browser Mockup component allows you to present screenshots, websites, or application UI previews inside a simulated browser interface shell.

## Usage

How to use the Browser Mockup component in its simplest form.

<ComponentShowcase>
  <RLABrowserMockup class="border border-border rounded-lg overflow-hidden shadow-md">
    <div class="p-8 bg-neutral-50 dark:bg-neutral-900 text-center">
      <h3 class="text-lg font-bold">Hello World</h3>
      <p class="text-sm text-muted-foreground mt-2">This content is displayed inside a browser mockup frame.</p>
    </div>
  </RLABrowserMockup>

  <div slot="code-astro">
    ```astro
    ---
    import RLABrowserMockup from "@rimelight/ui/components/astro/RLABrowserMockup.astro";
    ---

    <RLABrowserMockup class="border border-border rounded-lg overflow-hidden shadow-md">
      <div class="p-8 bg-neutral-50 dark:bg-neutral-900 text-center">
        <h3 class="text-lg font-bold">Hello World</h3>
        <p class="text-sm text-muted-foreground mt-2">This content is displayed inside a browser mockup frame.</p>
      </div>
    </RLABrowserMockup>
    ```

  </div>
</ComponentShowcase>
