The `PageSection` component helps layout large sections on your page, such as hero blocks, features listings, or newsletter subscription CTAs.

## Usage

<ComponentShowcase>
  <RLAPageSection
    title="Section Title"
    description="This is the main description detailing what this section covers."
  >
    <div class="p-4 bg-muted rounded text-sm text-center">
      Section body content goes here.
    </div>
  </RLAPageSection>

  <div slot="code-astro">
    ```astro
    ---
    import RLAPageSection from "@rimelight/ui/components/page-section/RLAPageSection.astro";
    ---

    <RLAPageSection
      title="Section Title"
      description="This is the main description detailing what this section covers."
    >
      <div>Section body content goes here.</div>
    </RLAPageSection>
    ```

  </div>
</ComponentShowcase>

## Examples

### Section Content Below Header Group (`slot="content"`)

Use `slot="content"` to place items (like tabs or filter bars) full-width below the header group (title, description, links, actions, and default side slot).

<ComponentShowcase>
  <RLAPageSection
    orientation="horizontal"
    title="Blog & Articles"
    description="Browse development logs and personal posts."
  >
    <button class="px-3 py-1.5 border rounded text-xs">Filter</button>
    <div slot="content" class="mt-4 p-4 border rounded">
      Full width section content below header and action slot.
    </div>
  </RLAPageSection>

  <div slot="code-astro">
    ```astro
    <RLAPageSection
      orientation="horizontal"
      title="Blog & Articles"
      description="Browse development logs and personal posts."
    >
      <button>Filter</button>
      <div slot="content">
        Full width section content below header and action slot.
      </div>
    </RLAPageSection>
    ```
  </div>
</ComponentShowcase>

### Hero Variant

Set `variant="hero"` to render the title as an `<h1>` heading with larger typography suited for page entries.

<ComponentShowcase>
  <RLAPageSection
    variant="hero"
    headline="NEW RELEASE"
    title="The Next-Gen UI Component Suite"
    description="Build accessible, beautiful layouts in minutes using modern integrations."
    links={[
      { label: "Get Started", href: "/docs", variant: "solid", color: "primary" },
      { label: "GitHub", href: "https://github.com", variant: "outline", color: "neutral" }
    ]}
  />

  <div slot="code-astro">

### Horizontal Layout

Set `orientation="horizontal"` to align the section headers beside the default content slot.

  >
    <div class="grid grid-cols-2 gap-4">
      <div class="p-4 border rounded">
        <h4 class="font-bold">Fast</h4>
