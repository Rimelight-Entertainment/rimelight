Rimelight UI automatically registers the **[@unocss/preset-icons](https://unocss.dev/presets/icons)** preset, providing a pure CSS icon system allowing you to use any [Iconify](https://iconify.design/) collection with just a class name.

## Usage

### Using with Component Props

Most Rimelight UI components (like Button, Badge, Callout) have an `icon` prop that accepts a string following the `i-<collection>-<icon>` format.

```astro
<RLAButton leadingIcon="i-lucide-rocket">Launch</RLAButton>
<RLACallout icon="i-lucide-info" title="Heads up!" />
```

### Using as CSS Classes

You can use icons anywhere in your HTML by adding the icon class directly. Most icons use **mask mode** and can be colored with `text-*` classes:

```astro
<div class="flex items-center gap-4 text-2xl">
  <span class="i-lucide-sun h-12 w-12 text-yellow-500" aria-label="Sun"></span>
  <span class="i-lucide-moon h-12 w-12 text-blue-500" aria-label="Moon"></span>
  <span class="i-logos-astro h-12 w-12" aria-label="Astro"></span>
</div>
```

## Icon Modes

UnoCSS renders icons in two modes:

| Mode           | Description                             | Color Method     | Example          |
| -------------- | --------------------------------------- | ---------------- | ---------------- |
| **Mask**       | Single-color icons using `currentColor` | `text-*` classes | `i-lucide-home`  |
| **Background** | Multi-color icons as background images  | Not customizable | `i-logos-github` |

### Mask Mode (Default for most icons)

Single-color icon sets like **Lucide**, **Heroicons**, and **Simple Icons** render in mask mode. Use `text-*` classes to change their color:

```astro
<span class="i-lucide-heart text-red-500 h-6 w-6" />
<span class="i-heroicons-bell text-blue-500 h-6 w-6" />
```

### Background Mode (Brand/Logo Icons)

Brand icons like **Logos** collection render in background mode with their original colors embedded. These cannot be recolored with CSS:

```astro
<span class="i-logos-github-icon h-6 w-6" />
<span class="i-logos-discord-icon h-6 w-6" />
```

### Forcing Mask Mode

To recolor a brand icon (making it single-color), append `?mask` to force mask mode, then use `text-*` classes:

```astro
<span class="i-logos-discord-icon?mask text-white h-6 w-6" />
<span class="i-logos-github-icon?mask text-white h-6 w-6" />
```

<RLACallout color="primary" variant="soft">
  When forcing mask mode on brand icons, they lose their original brand colors and become
  single-color. This is useful when you need icons to match your theme (e.g., white icons on a dark
  background).
</RLACallout>

### Dark Mode Support

Icons can be swapped based on color mode:

```astro
<button class="i-lucide-sun dark:i-lucide-moon h-6 w-6" aria-label="Toggle theme" />
```

## Icon Collections

By default, we recommend using the **Lucide** collection for a consistent and modern look across Rimelight projects.

- **Lucide:** `i-lucide-<icon-name>`
- **Simple Icons:** `i-simple-icons-<icon-name>`
- **Heroicons:** `i-heroicons-<icon-name>`
- **Logos:** `i-logos-<icon-name>`

You can browse all available icons at [icones.js.org](https://icones.js.org/).

## Global Customization

You can customize the default icons globally in your `astro.config.ts` integration options. You can map any default key to custom iconify classes or raw SVG strings:

```ts
import { defineConfig } from "astro/config"
import { ui } from "@rimelight/ui"

export default defineConfig({
  integrations: [
    ui({
      icons: {
        chevronDown: "i-heroicons-chevron-down-20-solid",
        close: "i-lucide-x",
        loaderCircle: "i-svg-spinners-clock"
      }
    })
  ]
})
```

These overrides are automatically integrated and safelisted by UnoCSS at build time.

## Setup

To use additional icon collections, install the corresponding `@iconify-json/*` package:

```bash
pnpm add -D @iconify-json/lucide @iconify-json/logos
```

The preset automatically detects installed icon sets in your project.

## Performance

Since `@unocss/preset-icons` generates icons as pure CSS (using mask or background-image), there are no JavaScript runtime costs. Only the icons you actually use are included in your CSS output. The icon data is loaded from `@iconify-json/*` packages at build time.

## Compatibility

Rimelight UI icons are generally compatible with any other icon implementation, just not within its component props. Other icon solutions may still be used within component slots as with any other Astro component.
