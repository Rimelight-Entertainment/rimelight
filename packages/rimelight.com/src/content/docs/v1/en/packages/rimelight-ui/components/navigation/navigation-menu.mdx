The `NavigationMenu` component provides a structured menu layout. In horizontal mode, it supports animated dropdown viewports that hover gracefully.

## Usage

<ComponentShowcase>
  <RLANavigationMenu
    items={[
      { label: "Home", href: "/" },
      {
        label: "Resources",
        children: [
          { label: "Documentation", description: "Learn how to use Rimelight", href: "/docs" },
          { label: "Playground", description: "Experiment in the browser", href: "/playground" }
        ]
      },
      { label: "Blog", href: "/blog" }
    ]}
  />

  <div slot="code-astro">
    ```astro
    ---
    import RLANavigationMenu from "@rimelight/ui/components/astro/RLANavigationMenu.astro";

    const items = [
      { label: "Home", href: "/" },
      {
        label: "Resources",
        children: [
          { label: "Documentation", description: "Learn how to use Rimelight", href: "/docs" },
          { label: "Playground", description: "Experiment in the browser", href: "/playground" }
        ]
      },
      { label: "Blog", href: "/blog" }
    ];
    ---

    <RLANavigationMenu items={items} />
    ```

  </div>
</ComponentShowcase>

## Examples

### Vertical Menu

Use `orientation="vertical"` to list navigation links in a sidebar structure.
