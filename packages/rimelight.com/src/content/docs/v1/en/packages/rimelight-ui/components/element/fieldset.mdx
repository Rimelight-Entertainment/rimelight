The `Fieldset` component is a themed block container designed for grouping related form controls to improve accessibility and visual structure.

## Usage

<ComponentShowcase>
  <RLAFieldset>
    <div class="flex flex-col gap-2">
      <label class="text-sm font-medium">Username</label>
      <input type="text" class="border p-1 rounded" placeholder="john_doe" />
    </div>
  </RLAFieldset>
