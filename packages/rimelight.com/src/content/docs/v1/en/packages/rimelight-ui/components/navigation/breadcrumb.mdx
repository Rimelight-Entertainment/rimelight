The `Breadcrumb` component renders a structured path indicating the hierarchy of pages. It automatically outputs Schema.org BreadcrumbList microdata for SEO.

## Usage

<ComponentShowcase>
  <RLABreadcrumb
    items={[
      { label: "Home", href: "/" },
      { label: "Components", href: "/components" },
      { label: "Breadcrumb" }
    ]}
  />

  <div slot="code-astro">
    ```astro
    ---
    import RLABreadcrumb from "@rimelight/ui/components/astro/RLABreadcrumb.astro";

    const items = [
      { label: "Home", href: "/" },
      { label: "Components", href: "/components" },
      { label: "Breadcrumb" }
    ];
    ---

    <RLABreadcrumb items={items} />
    ```

  </div>
</ComponentShowcase>

## Examples

### Custom Separator Icon

Use the `separatorIcon` prop to supply a custom separator icon class.

<ComponentShowcase>
  <RLABreadcrumb
    separatorIcon="i-lucide-slash"
    items={[
      { label: "Home", href: "/" },
      { label: "Components", href: "/components" },
      { label: "Breadcrumb" }
    ]}
  />

  <div slot="code-astro">
    ```astro
    <RLABreadcrumb
      separatorIcon="i-lucide-slash"
      items={[
        { label: "Home", href: "/" },
        { label: "Components", href: "/components" },
        { label: "Breadcrumb" }
      ]}
    />
    ```
  </div>
</ComponentShowcase>
