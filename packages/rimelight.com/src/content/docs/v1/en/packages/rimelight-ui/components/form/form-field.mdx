A wrapper component that provides a label, description, required indicator, and error messages for form controls.

## Usage

How to use the Form Field component to wrap an input.

<ComponentShowcase>
  <RLAFormField label="Username" id="username">
    <RLAInput id="username" placeholder="Enter your username" />
  </RLAFormField>

  <div slot="code-astro">
    ```astro
    ---
    import RLAFormField from "@rimelight/ui/components/astro/RLAFormField.astro";
    import RLAInput from "@rimelight/ui/components/astro/RLAInput.astro";
    ---

    <RLAFormField label="Username" id="username">
      <RLAInput id="username" placeholder="Enter your username" />
    </RLAFormField>
    ```

  </div>
</ComponentShowcase>

## Examples

### Required

Use the `required` prop to show a required asterisk next to the label.

<ComponentShowcase>
  <RLAFormField label="Email" id="email" required>
    <RLAInput id="email" type="email" placeholder="you@example.com" />
  </RLAFormField>

  <div slot="code-astro">
    ```astro
    ---
    import RLAFormField from "@rimelight/ui/components/astro/RLAFormField.astro";
    import RLAInput from "@rimelight/ui/components/astro/RLAInput.astro";
    ---

    <RLAFormField label="Email" id="email" required>
      <RLAInput id="email" type="email" placeholder="you@example.com" />
    </RLAFormField>
    ```

  </div>
</ComponentShowcase>

### Error and Description

Use the `description` and `error` props to provide help text and validation errors.

<ComponentShowcase>
  <RLAFormField
    label="Password"
    id="password"
    description="Must be at least 8 characters long."
    error="Password is too short"
  >
    <RLAInput id="password" type="password" />
  </RLAFormField>

  <div slot="code-astro">
    ```astro
    ---
    import RLAFormField from "@rimelight/ui/components/astro/RLAFormField.astro";
    import RLAInput from "@rimelight/ui/components/astro/RLAInput.astro";
    ---

    <RLAFormField
      label="Password"
      id="password"
      description="Must be at least 8 characters long."
      error="Password is too short"
    >
      <RLAInput id="password" type="password" />
    </RLAFormField>
    ```

  </div>
</ComponentShowcase>
