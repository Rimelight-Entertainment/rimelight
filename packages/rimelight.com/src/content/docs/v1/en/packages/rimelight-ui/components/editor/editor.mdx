The Editor component provides a structured wrapper to build code, markdown, or text editor panels.

## Usage

Use the Editor component to frame code files or text input areas.

<ComponentShowcase>
  <RLAEditor class="border border-neutral-200 rounded-lg flex flex-col h-48 bg-neutral-900 text-white font-mono text-xs">

      <span>main.js</span>
      <span>javascript</span>
    </div>
    <div class="p-4 flex-1 overflow-auto">
      <code class="text-emerald-400">console.log("Hello, Rimelight UI!");</code>
