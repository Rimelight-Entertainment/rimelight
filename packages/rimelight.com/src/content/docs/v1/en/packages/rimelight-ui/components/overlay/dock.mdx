A Dock component that renders a list of items/icons inside a modern, responsive shell-like navigation bar.

## Usage

How to use the Dock component.

<ComponentShowcase>
  <RLADock>
    <div class="p-2 bg-muted rounded-md flex gap-2">
      <span class="i-lucide-home size-6 cursor-pointer hover:text-primary" />
      <span class="i-lucide-settings size-6 cursor-pointer hover:text-primary" />
    </div>
  </RLADock>

  <div slot="code-astro">
    ```astro
    ---
    import RLADock from "@rimelight/ui/components/astro/RLADock.astro";
    ---

    <RLADock>
      <div class="p-2 bg-muted rounded-md flex gap-2">

        <span class="i-lucide-settings size-6 cursor-pointer hover:text-primary" />

    </RLADock>
    ```

  </div>
</ComponentShowcase>
