The Progress component displays a linear progress bar indicating the status of a task or operation.

## Usage

Use the Progress component with `value` and `max` props.

<ComponentShowcase>
  <RLAProgress value={60} max={100} />

  <div slot="code-astro">
    ```astro
    ---
    import RLAProgress from "@rimelight/ui/components/progress/RLAProgress.astro";
    ---

    <RLAProgress value={60} max={100} />
    ```

  </div>
</ComponentShowcase>

## Examples

### Color

Customize the color of the progress bar using the `color` prop.

<ComponentShowcase>
  <div class="flex flex-col gap-4 w-full">
    <RLAProgress value={30} color="success" />
    <RLAProgress value={50} color="warning" />
    <RLAProgress value={80} color="error" />
  </div>

  <div slot="code-astro">
    ```astro
    ---
    import RLAProgress from "@rimelight/ui/components/progress/RLAProgress.astro";
    ---

    <RLAProgress value={30} color="success" />
    <RLAProgress value={50} color="warning" />
    <RLAProgress value={80} color="error" />
    ```

  </div>
</ComponentShowcase>

### Size

Set the height of the progress bar using the `size` prop. Supported values are `sm`, `md` (default), and `lg`.

<ComponentShowcase>
  <div class="flex flex-col gap-4 w-full">
    <RLAProgress value={75} size="sm" />
    <RLAProgress value={75} size="md" />
    <RLAProgress value={75} size="lg" />
  </div>

  <div slot="code-astro">
    ```astro
    ---
    import RLAProgress from "@rimelight/ui/components/progress/RLAProgress.astro";
    ---

    <RLAProgress value={75} size="sm" />
    <RLAProgress value={75} size="md" />
    <RLAProgress value={75} size="lg" />
    ```

  </div>
</ComponentShowcase>
