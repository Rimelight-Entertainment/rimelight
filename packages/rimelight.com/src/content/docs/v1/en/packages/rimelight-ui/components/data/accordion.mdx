The Accordion component allows users to toggle the visibility of content sections. It can be used to display FAQs, details, or other collapsible information.

## Usage

Use the Accordion with an `items` array, or as a single collapsible element using the `summary` prop and slot content.

<ComponentShowcase>
  <RLAAccordion
    items={[
      { label: "What is Rimelight UI?", content: "Rimelight UI is a modern, lightweight component library built for fast web development." },
      { label: "Is it compatible with Astro?", content: "Yes! Rimelight UI is designed with first-class support for Astro components." }
    ]}
  />

  <div slot="code-astro">
    ```astro
    ---
    import RLAAccordion from "@rimelight/ui/components/accordion/RLAAccordion.astro";
    ---

    <RLAAccordion
      items={[
        { label: "What is Rimelight UI?", content: "Rimelight UI is a modern, lightweight component library built for fast web development." },
        { label: "Is it compatible with Astro?", content: "Yes! Rimelight UI is designed with first-class support for Astro components." }
      ]}
    />
    ```

  </div>
</ComponentShowcase>

## Examples

### Single Accordion with Default Slot

You can also use a single accordion item by passing a `summary` prop and putting the content in the default slot.

<ComponentShowcase>
  <RLAAccordion summary="Click to expand details">
    <p>This content is rendered inside the default slot of the Accordion component.</p>
  </RLAAccordion>

  <div slot="code-astro">
    ```astro
    ---
    import RLAAccordion from "@rimelight/ui/components/accordion/RLAAccordion.astro";
    ---

    <RLAAccordion summary="Click to expand details">
      <p>This content is rendered inside the default slot of the Accordion component.</p>
    </RLAAccordion>
    ```

  </div>
</ComponentShowcase>

### Multiple Open Allowed

By default, only one item in the accordion group can be open at a time. Set `multiple` to `true` to allow multiple items to be expanded simultaneously.

<ComponentShowcase>
  <RLAAccordion
    multiple
    items={[
      { label: "Section 1", content: "You can keep this open..." },
      { label: "Section 2", content: "...and open this section at the same time." }
    ]}
  />

  <div slot="code-astro">
    ```astro
    ---
    import RLAAccordion from "@rimelight/ui/components/accordion/RLAAccordion.astro";
    ---

    <RLAAccordion
      multiple
      items={[
        { label: "Section 1", content: "You can keep this open..." },
        { label: "Section 2", content: "...and open this section at the same time." }
      ]}
    />
    ```

  </div>
</ComponentShowcase>
