The `PageAside` component provides a themed block to wrap side content, side navigation lists, or tables of contents.

## Usage

<ComponentShowcase>
  <RLAPageAside>
    <div class="p-md text-sm border rounded">
      Aside Content
    </div>
  </RLAPageAside>

  <div slot="code-astro">

    ```astro
      <div>Aside Content</div>
    </RLAPageAside>
    ```

  </div>
</ComponentShowcase>
