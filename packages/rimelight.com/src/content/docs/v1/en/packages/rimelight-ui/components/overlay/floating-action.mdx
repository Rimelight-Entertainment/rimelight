A Floating Action Button (FAB) component that floats in a fixed position on the screen to trigger a primary action.

## Usage

How to use the FloatingAction component.

<ComponentShowcase>
  <RLAFloatingAction>
    <button class="bg-primary text-primary-foreground p-4 rounded-full shadow-lg hover:scale-105 transition-transform" aria-label="Add item">
      <span class="i-lucide-plus size-6" />
    </button>
  </RLAFloatingAction>

  <div slot="code-astro">
    ```astro
    ---
    import RLAFloatingAction from "@rimelight/ui/components/astro/RLAFloatingAction.astro";
    ---

    <RLAFloatingAction>
      <button class="bg-primary text-primary-foreground p-4 rounded-full shadow-lg hover:scale-105 transition-transform" aria-label="Add item">
        <span class="i-lucide-plus size-6" />
      </button>
    </RLAFloatingAction>
    ```

  </div>
</ComponentShowcase>

## Examples

### Position and Custom Styling

You can use standard utility classes to style the container or child button, such as placing it at custom locations or adding a badge.

<ComponentShowcase>
  <RLAFloatingAction class="right-8 bottom-8">
    <button class="bg-success text-success-foreground px-4 py-2.5 rounded-full shadow-lg hover:bg-success/90 flex items-center gap-2 font-medium" aria-label="Help">
      <span class="i-lucide-message-circle size-5" />
      <span>Support</span>
    </button>
  </RLAFloatingAction>

  <div slot="code-astro">

  </div>
</ComponentShowcase>
