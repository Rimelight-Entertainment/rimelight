## Usage

Use the rating component to display ratings or gather input.

<ComponentShowcase>
  <RLAInputRating defaultValue={3} />

  <div slot="code-astro">
    ```astro
    ---
    import RLAInputRating from "@rimelight/ui/components/input-rating/RLAInputRating.astro";
    ---

    <RLAInputRating defaultValue={3} />
    ```

  </div>
</ComponentShowcase>

### Step

Use the `step` prop to control the granularity of each star. Set it to `0.5` to allow half-star ratings.

<ComponentShowcase>
  <RLAInputRating step={0.5} defaultValue={3.5} hoverable={true} />

  <div slot="code-astro">
    ```astro
    ---
    import RLAInputRating from "@rimelight/ui/components/input-rating/RLAInputRating.astro";
    ---

    <RLAInputRating step={0.5} defaultValue={3.5} hoverable={true} />
    ```

  </div>
</ComponentShowcase>

### Length

Use the `length` prop to set the number of stars. Defaults to `5`.

<ComponentShowcase>
  <RLAInputRating length={10} step={0.5} defaultValue={7.5} hoverable={true} />

  <div slot="code-astro">
    ```astro
    ---
    import RLAInputRating from "@rimelight/ui/components/input-rating/RLAInputRating.astro";
    ---

    <RLAInputRating length={10} step={0.5} defaultValue={7.5} hoverable={true} />
    ```

  </div>
</ComponentShowcase>

### Clearable

Use the `clearable` prop to allow users to clear the rating by clicking on the currently selected value. Defaults to `false`.

<ComponentShowcase>
  <RLAInputRating clearable={true} defaultValue={3} />

  <div slot="code-astro">
    ```astro
    ---
    import RLAInputRating from "@rimelight/ui/components/input-rating/RLAInputRating.astro";
    ---

    <RLAInputRating clearable={true} defaultValue={3} />
    ```

  </div>
</ComponentShowcase>

### Hoverable

Use the `hoverable` prop to control whether the rating previews the value when hovering over the stars. Defaults to `false`.

<ComponentShowcase>
  <RLAInputRating hoverable={true} defaultValue={3} />

  <div slot="code-astro">
    ```astro
    ---
    import RLAInputRating from "@rimelight/ui/components/input-rating/RLAInputRating.astro";
    ---

    <RLAInputRating hoverable={true} defaultValue={3} />
    ```

  </div>
</ComponentShowcase>

### Icon

Use the `icon` prop to customize the icon used for stars. Defaults to `i-lucide-star` (or `star`).

<ComponentShowcase>
  <RLAInputRating icon="close" defaultValue={4} />

  <div slot="code-astro">
    ```astro
    ---
    import RLAInputRating from "@rimelight/ui/components/input-rating/RLAInputRating.astro";
    ---

    <RLAInputRating icon="close" defaultValue={4} />
    ```

  </div>
</ComponentShowcase>

### Empty Icon

Use the `empty-icon` prop to customize the icon used for empty stars. If not provided, uses the same icon as `icon`.

<ComponentShowcase>
  <RLAInputRating emptyIcon="chevronRight" icon="close" defaultValue={3} />

  </div>

### Orientation

Use the `orientation` prop to change the orientation of the rating. Defaults to `horizontal`.

<ComponentShowcase>
  <RLAInputRating orientation="vertical" defaultValue={4} />

  <div slot="code-astro">

### Disabled

Use the `disabled` prop to disable the InputRating component. When disabled, the component has reduced opacity (75%) and shows a `not-allowed` cursor to indicate it's not interactive.

<ComponentShowcase>
  <RLAInputRating disabled={true} defaultValue={3} />

  <div slot="code-astro">
    ```astro
    ---
    import RLAInputRating from "@rimelight/ui/components/input-rating/RLAInputRating.astro";
    ---

    <RLAInputRating disabled={true} defaultValue={3} />
    ```

  </div>
</ComponentShowcase>

### Readonly

Use the `readonly` prop to display a rating without allowing user interaction. Unlike `disabled`, it maintains normal appearance (full opacity, default cursor). Use when you want to display a rating that cannot be changed but should look normal.

<ComponentShowcase>
  <RLAInputRating readonly={true} defaultValue={4.5} />

  <div slot="code-astro">
    ```astro
    ---
    import RLAInputRating from "@rimelight/ui/components/input-rating/RLAInputRating.astro";
    ---

    <RLAInputRating readonly={true} defaultValue={4.5} />
    ```

  </div>
</ComponentShowcase>
