The ChatPrompt component provides the main typing field wrapper for user queries, designed to accommodate textareas, attachment links, and send buttons.

## Usage

Use the ChatPrompt component to structure the user input field.

<ComponentShowcase>
  <RLAChatPrompt class="flex gap-2 items-center border p-2 rounded-lg bg-card w-full">
    <textarea class="flex-1 bg-transparent resize-none outline-none text-sm px-2" placeholder="Ask anything..."></textarea>
    <button class="bg-primary text-white p-2 rounded-md hover:bg-primary/95 text-xs">Send</button>
  </RLAChatPrompt>

  <div slot="code-astro">
