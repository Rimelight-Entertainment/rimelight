The DashboardResizeHandle component acts as a visual and interactive handle to resize adjacent panels within a layout.

## Usage

Use the DashboardResizeHandle component between resizable panels.

<ComponentShowcase>
  <div class="flex h-24 border border-neutral-200 rounded">
    <div class="w-1/2 p-4 text-sm text-neutral-600">Left Panel</div>
    <RLADashboardResizeHandle class="w-1 bg-neutral-200 hover:bg-primary-500 cursor-col-resize transition-colors" />
    <div class="w-1/2 p-4 text-sm text-neutral-600">Right Panel</div>
  </div>

  <div slot="code-astro">
