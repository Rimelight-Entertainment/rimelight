The 3D Hover component creates an interactive 3D card tilt effect that responds to cursor movement.

## Usage

Wrap any block element with `RLA3dHover` to apply the tilt hover effect.

<ComponentShowcase>
  <RLA3dHover class="w-64 h-40 bg-gradient-to-tr from-indigo-500 to-purple-600 rounded-xl shadow-lg flex items-center justify-center text-white font-bold text-lg select-none cursor-pointer">
    Tilt Me!
  </RLA3dHover>

  <div slot="code-astro">
    ```astro
    ---
    import RLA3dHover from "@rimelight/ui/components/astro/RLA3dHover.astro";
    ---

    <RLA3dHover class="w-64 h-40 bg-gradient-to-tr from-indigo-500 to-purple-600 rounded-xl shadow-lg flex items-center justify-center text-white font-bold text-lg select-none cursor-pointer">
      Tilt Me!

    ```

  </div>
</ComponentShowcase>
