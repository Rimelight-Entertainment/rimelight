A slider component that allows users to select a value or range of values by sliding a thumb along a track.

## Usage

How to use the Slider component in its simplest form.

<ComponentShowcase>
  <RLASlider value={50} class="w-full max-w-xs" />

  <div slot="code-astro">
    ```astro
    ---
    import RLASlider from "@rimelight/ui/components/astro/RLASlider.astro";
    ---

    <RLASlider value={50} class="w-full max-w-xs" />
    ```

  </div>
</ComponentShowcase>

## Examples

### Range and Step Customization

You can define custom `min`, `max`, and `step` values for the slider.

<ComponentShowcase>
  <RLASlider min={0} max={10} step={2} value={6} class="w-full max-w-xs" />

  <div slot="code-astro">

  </div>
</ComponentShowcase>
