A multi-line text input control for getting user feedback, comments, or longer text entries.

## Usage

How to use the Textarea component in its simplest form.

<ComponentShowcase>
  <RLATextarea placeholder="Enter your comments here..." />

  <div slot="code-astro">
    ```astro
    ---
    import RLATextarea from "@rimelight/ui/components/textarea/RLATextarea.astro";
    ---

    <RLATextarea placeholder="Enter your comments here..." />
    ```

  </div>
</ComponentShowcase>

## Examples

### Custom Rows

Use the `rows` prop to define the default height of the input area.

<ComponentShowcase>
  <RLATextarea placeholder="A taller text area..." rows={8} />

  <div slot="code-astro">
    ```astro
    ---
    import RLATextarea from "@rimelight/ui/components/textarea/RLATextarea.astro";
    ---

    <RLATextarea placeholder="A taller text area..." rows={8} />
    ```

  </div>
</ComponentShowcase>

### Error State

Use the `error` prop to display the textarea in a validation failure state.

<ComponentShowcase>
  <RLATextarea placeholder="Required field" error />

  <div slot="code-astro">
    ```astro
    ---
    import RLATextarea from "@rimelight/ui/components/textarea/RLATextarea.astro";
    ---

    <RLATextarea placeholder="Required field" error />
    ```

  </div>
</ComponentShowcase>
