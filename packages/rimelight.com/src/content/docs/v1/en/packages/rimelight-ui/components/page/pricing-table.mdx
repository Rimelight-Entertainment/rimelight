The `PricingTable` component aligns multiple `PricingPlan` cards side-by-side in a responsive grid.

## Usage

  <RLAPricingTable>
    <div class="grid grid-cols-1 md:grid-cols-2 gap-md w-full">

        <p>$19/mo</p>
      </div>
      <div class="border p-lg rounded flex flex-col items-center">

  </div>
</ComponentShowcase>
