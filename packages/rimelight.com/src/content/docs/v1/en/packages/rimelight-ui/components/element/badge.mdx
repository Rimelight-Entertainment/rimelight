A small inline label used to highlight statuses, categories, counts, or tags. Supports multiple visual variants, color themes, sizes, and shape options.

## Usage

<ComponentShowcase>
  <RLABadge label="Badge" />

  <div slot="code-astro">
    ```astro
    ---
    import RLABadge from "@rimelight/ui/components/astro/RLABadge.astro";
    ---

    <RLABadge label="Badge" />
    ```

  </div>

  <div slot="code-vue">
    ```vue
    <script setup>
    import RLVBadge from "@rimelight/ui/components/vue/RLVBadge.vue";
    </script>

    <template>
      <RLVBadge label="Badge" />
    </template>
    ```

  </div>
</ComponentShowcase>
