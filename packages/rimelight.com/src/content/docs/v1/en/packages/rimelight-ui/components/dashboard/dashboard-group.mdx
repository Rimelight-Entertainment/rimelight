The DashboardGroup component is used to group dashboard sections or panels, providing structure and layout spacing.

## Usage

Use the DashboardGroup component to contain and organize related dashboard elements.

<ComponentShowcase>
  <RLADashboardGroup class="p-6 border border-dashed border-neutral-300 rounded-lg">
    <p class="text-neutral-500">Dashboard Group Content</p>
  </RLADashboardGroup>

  <div slot="code-astro">
    ```astro
    ---
    import RLADashboardGroup from "@rimelight/ui/components/astro/RLADashboardGroup.astro";
    ---

    <RLADashboardGroup class="p-6 border border-dashed border-neutral-300 rounded-lg">
      <p class="text-neutral-500">Dashboard Group Content</p>
    </RLADashboardGroup>
    ```

  </div>
</ComponentShowcase>
