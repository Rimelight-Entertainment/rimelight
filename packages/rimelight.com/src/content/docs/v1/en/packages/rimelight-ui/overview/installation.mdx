To use Rimelight UI in an Astro project, install the package and register the integration.

## Installation

<RLASteps>
  <li>
    **Install the package**

    Add `@rimelight/ui` to your project using your preferred package manager:

    <RLAPackageManagers pkg="@rimelight/ui" type="add" />

  </li>

  <li>
    **Register the integration**

    Add the `ui()` integration to your `astro.config.ts`:

    ```typescript
    // astro.config.ts
    import { ui } from "@rimelight/ui/integrations"
    import { defineConfig } from "astro/config"

    export default defineConfig({
      integrations: [
        ui({
          // Optional: provide global UI overrides
          ui: {
            button: {
              defaultVariants: { color: "secondary" }
            }
          }
        })
      ]
    })
    ```

  </li>

  <li>
    **Start building**

    Import any component directly in your `.astro` or `.mdx` files — no global registration needed:

    ```astro
    ---
    import RLAButton from "@rimelight/ui/components/astro/RLAButton.astro"
    ---

    <RLAButton label="Hello world" color="primary" />
    ```

  </li>
</RLASteps>
