To use Rimelight UI in an Astro project, install the package and register the integration.

## Installation

<RLASteps>
  <li>
    **Install the package**

    Add `@rimelight/ui` to your project using your preferred package manager:

    <RLAPackageManagers pkg="@rimelight/ui" type="add" />

  </li>

  <li>
    **Register the integration**

    Add the `ui()` integration to your `astro.config.ts`:

    ```typescript
    // astro.config.ts
    import { ui } from "@rimelight/ui"
    import { defineConfig } from "astro/config"

    export default defineConfig({
      integrations: [
        ui({
          // Optional: provide global UI overrides
          components: {
            themes: {
              button: {
                defaultVariants: { color: "secondary" }
              }
            }
          }
        })
      ]
    })
    ```

    <RLACallout color="error">
      RimelightUI injects the `@unocss/astro` integration internally, and it should not be added to the integrations list.
    </RLACallout>

  </li>

  <li>
    **Start building**

    Import any component directly in your `.astro` or `.mdx` files - no global registration needed:

    ```astro
    ---
    import RLAButton from "@rimelight/ui/components/button/RLAButton.astro"
    ---

    <RLAButton label="Hello world" color="primary" />
    ```

  </li>
</RLASteps>

## Configuration Options

Below are the configuration options you can pass to the `ui()` integration:

### UnoCSS Presets

By default, Rimelight UI enables three presets for UnoCSS (`wind`, `typography`, and `icons`). If you want to disable any of these (for example, to prevent conflicts or reduce CSS output), you can configure them in the `presets` object:

```typescript
ui({
  presets: {
    wind: true, // Toggle presetWind4 (default: true)
    typography: false, // Toggle presetTypography (default: true)
    icons: true // Toggle presetIcons (default: true)
  }
})
```

### Raw UnoCSS Config

If you want to configure additional UnoCSS rules, shortcuts, or add custom presets, you can pass them directly via the `unocss` property. The configuration is merged with Rimelight UI's internal defaults:

```typescript
ui({
  unocss: {
    presets: [
      // Add custom presets alongside Rimelight UI's presets
      myCustomPreset()
    ],
    rules: [
      // Add custom style rules
      [
        /^custom-(.+)$/,
        ([, name]) => ({
          /* ... */
        })
      ]
    ]
  }
})
```
