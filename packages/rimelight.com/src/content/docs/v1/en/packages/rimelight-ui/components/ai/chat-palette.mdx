The ChatPalette component is a contextual wrapper used for displaying suggested prompts, action buttons, or model selection panels inside the chat assistant UI.

## Usage

Use the ChatPalette component to offer quick action choices to users.

<ComponentShowcase>
  <RLAChatPalette class="border rounded-lg p-4 bg-card flex flex-col gap-2 max-w-sm">
    <div class="text-xs font-semibold text-muted mb-1">SUGGESTED ACTIONS</div>
    <button class="text-left text-sm p-2 hover:bg-muted rounded border">Summarize this page</button>
    <button class="text-left text-sm p-2 hover:bg-muted rounded border">Write a professional email</button>
  </RLAChatPalette>

  <div slot="code-astro">
    ```astro
    ---

    ```

  </div>
