The Main component renders a semantic layout wrapper that works in conjunction with the Header component to structure core page contents.

## Usage

The Main component renders a `<main>` element designed to adjust to the viewport's available height.

<ComponentShowcase>
  <RLAMain>
    <div class="p-6">Content Area</div>
  </RLAMain>

  <div slot="code-astro">
    ```astro
    ---
    import RLAMain from "@rimelight/ui/components/astro/RLAMain.astro";
    ---

    <RLAMain>
      <div class="p-6">Content Area</div>
    </RLAMain>
    ```

  </div>
</ComponentShowcase>

## Examples

### Custom Element Tag

Use the `as` prop to render a different semantic HTML element tag instead of `main`.

<ComponentShowcase>
  <RLAMain as="section">
    <div class="p-6">Content wrapped in a section element</div>
  </RLAMain>

  <div slot="code-astro">
    ```astro
    ---
    import RLAMain from "@rimelight/ui/components/astro/RLAMain.astro";
    ---

    <RLAMain as="section">
      <div class="p-6">Content wrapped in a section element</div>
    </RLAMain>
    ```

  </div>
</ComponentShowcase>
