The Head component provides a unified shell for configuring SEO tags, Open Graph and Twitter cards, viewport configuration, canonical URLs, and RSS feeds.

## Usage

Use the Head component inside the HTML `<head>` tag of your page layouts.

<ComponentShowcase>
  <div class="p-6 text-center text-muted text-sm border border-dashed rounded-lg">
    The Head component manages document metadata, scripts, and links within the HTML <code>&lt;head&gt;</code> element.
  </div>

  <div slot="code-astro">
    ```astro
    ---
    import RLAHead from "@rimelight/ui/components/head/RLAHead.astro";
    ---

    <head>
      <RLAHead
        title="Home Page"
        description="Welcome to my custom Rimelight UI website."
        transitions={true}
      />
    </head>
    ```

  </div>
</ComponentShowcase>
