A wrapper component for HTML form elements, supporting theme variations and layout configuration.

## Usage

How to use the Form component to contain other form elements.

<ComponentShowcase>
  <RLAForm class="space-y-4">
    <div class="text-sm font-semibold">Form Content</div>
  </RLAForm>

  <div slot="code-astro">
    ```astro
    ---
    import RLAForm from "@rimelight/ui/components/form/RLAForm.astro";
    ---

    <RLAForm class="space-y-4">
      <div class="text-sm font-semibold">Form Content</div>
    </RLAForm>
    ```

  </div>
</ComponentShowcase>
