The Header component provides a unified structural shell for application and website navigation. Built with a robust CSS-first architecture, it handles fixed positioning, dynamic z-indexing, and multiple-layer stacking automatically.

## Usage

Use the Header component with slot placements to organize logo, navigational links, and user profiles.

## Examples

### Dynamic Stacking

A core feature of the Rimelight Header is its ability to stack multiple fixed headers on top of each other.

By passing `fixed={true}` and assigning a sequential `stackIndex` (e.g., `0` for the top-most header, `1` for the one below it), the components will register with the global header stack manager. This manager dynamically calculates offsets and synchronizes visibility states across boundaries.

### Scroll Hide

Passing `hideOnScroll={true}` attaches an optimized scroll listener to the header. When the user scrolls down, the header slides up and out of view. When they scroll back up, it slides down.

If you have multiple stacked headers, hiding a layer will cause all layers beneath it to smoothly slide up and fill the gap.
