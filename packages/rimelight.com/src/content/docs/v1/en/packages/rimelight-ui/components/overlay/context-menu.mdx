A Context Menu component that is triggered when a user right-clicks on a target area.

## Usage

How to use the Context Menu component.

<ComponentShowcase>
  <RLAContextMenu>
    <div class="p-8 border border-dashed rounded text-center cursor-context-menu">Right-click here</div>
  </RLAContextMenu>

  <div slot="code-astro">
    ```astro
    ---
    import RLAContextMenu from "@rimelight/ui/components/context-menu/RLAContextMenu.astro";
    ---

    <RLAContextMenu>
      <div class="p-8 border border-dashed rounded text-center cursor-context-menu">Right-click here</div>
    </RLAContextMenu>
    ```

  </div>
</ComponentShowcase>

## Examples
