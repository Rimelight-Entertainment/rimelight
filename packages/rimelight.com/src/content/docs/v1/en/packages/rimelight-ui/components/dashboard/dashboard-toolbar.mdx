The DashboardToolbar component is a flexible container used for filters, actions, and layouts at the top of dashboard content views.

## Usage

Use the DashboardToolbar component to align filtering and action buttons on a dashboard page.

<ComponentShowcase>
  <RLADashboardToolbar class="flex items-center justify-between p-3 bg-neutral-50 border border-neutral-200 rounded">
    <div class="flex items-center gap-2">
      <span class="text-xs font-medium text-neutral-500">Filter:</span>
      <select class="text-xs border border-neutral-300 rounded px-2 py-1 bg-white"><option>All Time</option></select>
    </div>
    <button class="text-xs bg-primary-600 text-white px-3 py-1 rounded cursor-pointer">Export CSV</button>
  </RLADashboardToolbar>
