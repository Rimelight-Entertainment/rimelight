The ChatMessages component acts as the message stream layer within a chat view, holding the log of conversational turns.

## Usage

Use the ChatMessages component to group and align chat message items.

<ComponentShowcase>
  <RLAChatMessages class="flex flex-col gap-md max-h-[300px] overflow-y-auto p-4 border rounded-lg">
    <RLAChatMessage class="bg-muted p-3 rounded-md self-end max-w-[70%]">
      Can I customize the styles of the chat bubble?
    </RLAChatMessage>
    <RLAChatMessage class="bg-primary/15 p-3 rounded-md self-start max-w-[70%]">
      Yes! You can pass custom classes or override the Tailwind styling theme.
    </RLAChatMessage>
  </RLAChatMessages>
