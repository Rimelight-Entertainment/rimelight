The `Tabs` component organizes content into logical panels, allowing users to toggle between different views without page refreshes.

## Usage

<ComponentShowcase>
  <RLATabs
    items={[
      { label: "Account", value: "account", icon: "i-lucide-user" },
      { label: "Password", value: "password", icon: "i-lucide-lock" }
    ]}
  >
    <div role="tabpanel" data-value="account" class="p-4 border border-t-0 rounded-b">
      Manage your account details and profile information here.
    </div>
    <div role="tabpanel" data-value="password" class="p-4 border border-t-0 rounded-b">
      Change your password and manage security keys here.
    </div>
  </RLATabs>

  <div slot="code-astro">
    ```astro
    ---
    import RLATabs from "@rimelight/ui/components/tabs/RLATabs.astro";

    const items = [
      { label: "Account", value: "account", icon: "i-lucide-user" },
      { label: "Password", value: "password", icon: "i-lucide-lock" }
    ];
    ---

    <RLATabs items={items}>
      <div role="tabpanel" data-value="account">
        Manage your account details and profile information here.
      </div>
      <div role="tabpanel" data-value="password">
        Change your password and manage security keys here.
      </div>
    </RLATabs>
    ```
  </div>
</ComponentShowcase>

### Items

Use the `items` prop as an array of objects with properties like `label`, `value`, `icon`, `badge`, `disabled`, and `content`.

### Content

Set the `content` prop to `false` to turn the Tabs into a toggle-only tab bar without rendering content panels automatically.

<ComponentShowcase>
  <RLATabs
    content={false}
    items={[
      { label: "Overview", value: "overview" },
      { label: "Analytics", value: "analytics" },
      { label: "Reports", value: "reports" }
    ]}
  />

  <div slot="code-astro">
    ```astro
    <RLATabs
      content={false}
      items={[
        { label: "Overview", value: "overview" },
        { label: "Analytics", value: "analytics" },
        { label: "Reports", value: "reports" }
      ]}
    />
    ```
  </div>
</ComponentShowcase>

### Variant

Use the `variant` prop to toggle between `pill` and `underline` tab styles.

<ComponentShowcase>
  <RLATabs
    variant="underline"
    items={[
      { label: "Account", value: "account" },
      { label: "Password", value: "password" }
    ]}
  >
    <div role="tabpanel" data-value="account" class="p-4">Account content panel.</div>
    <div role="tabpanel" data-value="password" class="p-4">Password content panel.</div>
  </RLATabs>

  <div slot="code-astro">

### Size

Use the `size` prop (`xs`, `sm`, `md`, `lg`, `xl`) to change the scale of the tabs.

<ComponentShowcase>
  <RLATabs
    size="sm"
    variant="pill"
    items={[
      { label: "General", value: "general" },
      { label: "Security", value: "security" }
    ]}
  >
    <div role="tabpanel" data-value="general" class="p-3 text-sm">General options</div>
    <div role="tabpanel" data-value="security" class="p-3 text-sm">Security options</div>
  </RLATabs>

  <div slot="code-astro">
    ```astro
    <RLATabs
      size="sm"
      variant="pill"
      items={[
        { label: "General", value: "general" },

    />
    ```
  </div>
</ComponentShowcase>

### Orientation

Use the `orientation` prop to align tabs vertically (`vertical`) or horizontally (`horizontal`).

  <RLATabs

    <div role="tabpanel" data-value="profile" class="p-4">Profile configuration.</div>
    <div role="tabpanel" data-value="notifications" class="p-4">Notification preferences.</div>

### With Badges, Icons, and Disabled Items

You can add icons and badges to individual tab items, or set items as disabled.
