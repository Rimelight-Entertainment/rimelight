The `Link` component wraps standard anchor navigation. It automatically detects external URLs to apply secure targets (`target="_blank"`, `rel="noopener noreferrer"`) and appends an external-link icon.

## Usage

Use the `label` prop to set the link text.

<ComponentShowcase>
  <RLALink href="/" label="Home" />

  <div slot="code-astro">
    ```astro
    ---
    import RLALink from "@rimelight/ui/components/link/RLALink.astro";
    ---

    <RLALink href="/" label="Home" />
    ```

  </div>
  <div slot="code-vue">
    ```vue
    <script setup lang="ts">
    import RLVLink from "@rimelight/ui/components/link/RLVLink.vue"
    </script>

    <template>
      <RLVLink href="/" label="Home" />
    </template>
    ```

  </div>
  <div slot="code-solid">
    ```tsx
    import RLSLink from "@rimelight/ui/components/link/RLSLink"

    <RLSLink href="/" label="Home" />
    ```

  </div>
</ComponentShowcase>

### No External Icon

By default, external URLs (starting with `http`, `https`, or `//`) automatically render with target `_blank` and an external link icon. This can be disabled by the `noExternalIcon` prop.

<ComponentShowcase>
  <div class="flex flex-col gap-2 items-start">
    <RLALink href="https://rimelight.com" label="Home" />
    <RLALink href="https://rimelight.com" noExternalIcon label="Home" />
  </div>

  <div slot="code-astro">
    ```astro
    <RLALink href="https://rimelight.com" label="Home" />
    <RLALink href="https://rimelight.com" noExternalIcon label="Home" />
    ```
  </div>
  <div slot="code-vue">
    ```vue
    <RLVLink href="https://rimelight.com" label="Home" />
    <RLVLink href="https://rimelight.com" noExternalIcon label="Home" />
    ```
  </div>
  <div slot="code-solid">
    ```tsx
    <RLSLink href="https://rimelight.com" label="Home" />
    <RLSLink href="https://rimelight.com" noExternalIcon label="Home" />
    ```
  </div>
</ComponentShowcase>

### Accessible Label

Provide an `ariaLabel` for screen readers. When set on an external link, the "(opens in a new tab)" hint is suppressed in favor of your custom label.

<ComponentShowcase>
  <RLALink href="https://rimelight.com" ariaLabel="Visit the Rimelight homepage" label="Home" />

  <div slot="code-astro">
    ```astro
    <RLALink href="https://rimelight.com" ariaLabel="Visit the Rimelight homepage" label="Home" />
    ```
  </div>
  <div slot="code-vue">
    ```vue
    <RLVLink href="https://rimelight.com" ariaLabel="Visit the Rimelight homepage" label="Home" />
    ```

  </div>
  <div slot="code-solid">

</ComponentShowcase>

### Force External

Mark any link as external with the `external` prop, even if the URL is relative.

<ComponentShowcase>
  <RLALink href="/docs" external label="Home" />

  <div slot="code-astro">
    ```astro
    <RLALink href="/docs" external label="Home" />
    ```
  </div>
  <div slot="code-vue">
    ```vue
    <RLVLink href="/docs" :external="true" label="Home" />
    ```
  </div>
  <div slot="code-solid">
    ```tsx
    <RLSLink href="/docs" external label="Home" />
    ```
  </div>
</ComponentShowcase>
