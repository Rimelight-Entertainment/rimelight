## Usage

How to use the Link component in its simplest form.

<ComponentShowcase>
  <RLALink label="Link" href="/" />

  <div slot="code-astro">
    ```astro
    ---
    import RLALink from "@rimelight/ui/components/link/RLALink.astro";
    ---

    <RLALink label="Home" href="/" />
    ```

  </div>
</ComponentShowcase>

## Examples

### Label

Use the `label` prop to set the label of the Link.

<ComponentShowcase>
  <RLALink label="Home" href="/" />

  <div slot="code-astro">

    ```astro
    ---

    <RLALink label="Home" href="/" />
    ```

  </div>
</ComponentShowcase>

### Leading Icon

Add an icon before the link label using the `leadingIcon` prop.

<ComponentShowcase>

  </div>
</ComponentShowcase>

### External Icon

By default, external URLs (starting with `http`, `https`, or `//`) automatically render with target `_blank` and an external link icon. This can be disabled by the `noExternalIcon` prop.

<ComponentShowcase>
  <div class="flex flex-col gap-2 items-start">
    <RLALink href="https://rimelight.com" label="Home" />
    <RLALink href="https://rimelight.com" noExternalIcon label="Home" />
  </div>

  <div slot="code-astro">
    ```astro
    <RLALink href="https://rimelight.com" label="Home" />
    <RLALink href="https://rimelight.com" noExternalIcon label="Home" />
    ```
  </div>
  <div slot="code-vue">
    ```vue
    <RLVLink href="https://rimelight.com" label="Home" />
    <RLVLink href="https://rimelight.com" noExternalIcon label="Home" />
    ```
  </div>
  <div slot="code-solid">
    ```tsx
    <RLSLink href="https://rimelight.com" label="Home" />
    <RLSLink href="https://rimelight.com" noExternalIcon label="Home" />
    ```
  </div>
</ComponentShowcase>

### Force External

Mark any link as external with the `external` prop, even if the URL is relative.

<ComponentShowcase>
  <RLALink href="/" external label="Home" />

  <div slot="code-astro">

  </div>
  <div slot="code-vue">
    ```vue

    ```
  </div>
  <div slot="code-solid">
    ```tsx
    <RLSLink href="/" external label="Home" />
    ```
  </div>
</ComponentShowcase>

### Prefetch

Enable Astro's built-in prefetching by setting the `prefetch` prop. Accepts `true` (defaults to `"viewport"`) or a specific trigger: `"hover"`, `"tap"`, `"load"`, or `"viewport"`.

<ComponentShowcase>
  <div class="flex flex-col gap-2 items-start">
    <RLALink href="/getting-started" prefetch label="Prefetch (viewport)" />
    <RLALink href="/installation" prefetch="hover" label="Prefetch on hover" />
  </div>

  <div slot="code-astro">
    ```astro
    <RLALink href="/getting-started" prefetch label="Prefetch (viewport)" />
    <RLALink href="/installation" prefetch="hover" label="Prefetch on hover" />
    ```
  </div>
  <div slot="code-vue">
    ```vue
    <RLVLink href="/getting-started" prefetch label="Prefetch (viewport)" />
    <RLVLink href="/installation" prefetch="hover" label="Prefetch on hover" />
    ```
  </div>
  <div slot="code-solid">
    ```tsx
    <RLSLink href="/getting-started" prefetch label="Prefetch (viewport)" />
    <RLSLink href="/installation" prefetch="hover" label="Prefetch on hover" />
    ```
  </div>
</ComponentShowcase>

### i18n Auto-Localization

When Astro i18n is configured, the link automatically localizes paths to the current locale. Set `locale` to `false` to disable, or pass a specific locale code.

<ComponentShowcase>
  <div class="flex flex-col gap-2 items-start">
    <RLALink href="/docs" label="Auto-localized" />
    <RLALink href="/docs" locale={false} label="Not localized" />
    <RLALink href="/docs" locale="pt" label="Portuguese" />
  </div>

  <div slot="code-astro">
    ```astro
    <RLALink href="/docs" label="Auto-localized" />
    <RLALink href="/docs" locale={false} label="Not localized" />
    <RLALink href="/docs" locale="pt" label="Portuguese" />
    ```
  </div>
  <div slot="code-vue">
    ```vue
    <RLVLink href="/docs" label="Auto-localized" />
    <RLVLink href="/docs" locale="false" label="Not localized" />
    <RLVLink href="/docs" locale="pt" label="Portuguese" />
    ```
  </div>
  <div slot="code-solid">
    ```tsx

    <RLSLink href="/docs" locale="pt" label="Portuguese" />
    ```

  </div>

### Raw Mode

When `raw` is set, only `class` is applied — all theme styles are skipped. Use this when wrapping custom content like images or cards where the link's default layout classes would interfere.

<ComponentShowcase>
  <div class="flex items-center gap-4">
    <RLALink href="/" raw>
      <img src="https://placehold.co/48" alt="" class="rounded-md" />
    </RLALink>
  </div>

  <div slot="code-astro">
    ```astro
    <RLALink href="/" raw>
      <img src="https://placehold.co/48" alt="" />
    </RLALink>
    ```
  </div>
  <div slot="code-vue">
    ```vue
    <RLVLink href="/" raw>
      <img src="https://placehold.co/48" alt="" />
    ```

  </div>

### Accessible Label

Provide an `ariaLabel` for screen readers. When set on an external link, the "(opens in a new tab)" hint is suppressed in favor of your custom label.

<ComponentShowcase>
  <RLALink href="https://rimelight.com" ariaLabel="Visit the Rimelight homepage" label="Home" />

  <div slot="code-astro">
