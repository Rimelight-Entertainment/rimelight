The `Label` component provides a styled, accessible text label for form controls.

## Usage

<ComponentShowcase>
  <RLALabel for="email-input">Email Address</RLALabel>

  <div slot="code-astro">
    ```astro
    ---
    import RLALabel from "@rimelight/ui/components/astro/RLALabel.astro";
    ---

    <RLALabel for="email-input">Email Address</RLALabel>
    ```

  </div>
</ComponentShowcase>

## Examples

### Sizes

Use the `size` prop to change the font size of the label.

<ComponentShowcase>
  <div class="flex flex-col gap-2">

    <RLALabel size="md">Medium Label (Default)</RLALabel>
    <RLALabel size="lg">Large Label</RLALabel>
  </div>

  <div slot="code-astro">

  </div>
</ComponentShowcase>
