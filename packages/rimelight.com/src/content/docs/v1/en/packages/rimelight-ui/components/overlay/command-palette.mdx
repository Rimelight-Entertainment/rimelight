A Command Palette component that displays a search input and list of actions to navigate or trigger commands.

## Usage

How to use the Command Palette component.

<ComponentShowcase>
  <RLACommandPalette>
    <div class="p-4 text-center text-muted-foreground">Command Palette Content</div>
  </RLACommandPalette>

  <div slot="code-astro">
    ```astro
    ---
    import RLACommandPalette from "@rimelight/ui/components/astro/RLACommandPalette.astro";
    ---

    <RLACommandPalette>
      <div class="p-4 text-center text-muted-foreground">Command Palette Content</div>
    </RLACommandPalette>
    ```

  </div>
</ComponentShowcase>

## Examples

### Custom Content

You can render any custom content inside the Command Palette.

<ComponentShowcase>
  <RLACommandPalette class="border border-primary/20 rounded-lg">
    <div class="p-6 text-center">
      <p class="font-medium">Search for commands...</p>
      <p class="text-sm text-muted-foreground mt-1">Press ESC to exit</p>
    </div>
  </RLACommandPalette>

  <div slot="code-astro">
    ```astro
    ---
    import RLACommandPalette from "@rimelight/ui/components/astro/RLACommandPalette.astro";
    ---

    <RLACommandPalette class="border border-primary/20 rounded-lg">
      <div class="p-6 text-center">
        <p class="font-medium">Search for commands...</p>
        <p class="text-sm text-muted-foreground mt-1">Press ESC to exit</p>
      </div>
    </RLACommandPalette>
    ```

  </div>
</ComponentShowcase>
