The `Pagination` component displays next/prev arrows and a list of page links with automatic ellipsis generation for long listings.

## Usage

<ComponentShowcase>
  <RLAPagination currentPage={2} totalPages={10} baseUrl="?page=" />

  <div slot="code-astro">
    ```astro
    ---
    import RLAPagination from "@rimelight/ui/components/astro/RLAPagination.astro";
    ---

    <RLAPagination currentPage={2} totalPages={10} baseUrl="?page=" />
    ```

  </div>
</ComponentShowcase>

## Examples

### Edge States (First Page)
