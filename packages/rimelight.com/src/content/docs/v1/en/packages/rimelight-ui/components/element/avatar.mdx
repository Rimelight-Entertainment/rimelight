Display a user's profile picture, initials, or a fallback icon. Supports badge indicators, profile text layout, and full slot customization.

## Usage

<ComponentShowcase>
  <RLAAvatar src="https://i.pravatar.cc/150?img=3" alt="Jane Doe" />

  <div slot="code-astro">
    ```astro
    ---
    import RLAAvatar from "@rimelight/ui/components/astro/RLAAvatar.astro";
    ---

    <RLAAvatar src="https://i.pravatar.cc/150?img=3" alt="Jane Doe" />
    ```

  </div>

  <div slot="code-vue">
    ```vue
    <script setup>
    import RLVAvatar from "@rimelight/ui/components/vue/RLVAvatar.vue";
    </script>

    <template>
      <RLVAvatar src="https://i.pravatar.cc/150?img=3" alt="Jane Doe" />
    </template>
    ```

  </div>
</ComponentShowcase>
