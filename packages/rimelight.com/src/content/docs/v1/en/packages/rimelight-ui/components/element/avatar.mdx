Display a user's profile picture, initials, or a fallback icon. Supports badge indicators, profile text layout, and full slot customization.

## Usage

<ComponentShowcase>
  <RLAAvatar src="https://i.pravatar.cc/150?img=3" alt="Jane Doe" />

  <div slot="code-astro">
    ```astro
    ---
    import RLAAvatar from "@rimelight/ui/components/avatar/RLAAvatar.astro";
    ---

    <RLAAvatar src="https://i.pravatar.cc/150?img=3" alt="Jane Doe" />
    ```

  </div>
</ComponentShowcase>

## Examples

### Sizes

Use the `size` prop to change the size of the avatar.

<ComponentShowcase
  togglingPattern="tab-segmented"
  componentName="RLAAvatar"
  propsConfig={{
    size: ["xs", "sm", "md", "lg", "xl", "2xl"]
  }}
  defaultProps={{
    size: "md"
  }}
>
  <RLAAvatar src="https://i.pravatar.cc/150?img=3" alt="Jane Doe" />
</ComponentShowcase>

### Colors

Use the `color` prop to set the tint applied to the avatar background and text when no image is provided.

<ComponentShowcase
  togglingPattern="tab-segmented"
  componentName="RLAAvatar"
  propsConfig={{
    color: ["primary", "secondary", "info", "success", "warning", "error", "neutral"]
  }}
  defaultProps={{
    color: "primary"
  }}
>
  <RLAAvatar initials="JD" />
</ComponentShowcase>

### Fallback / Initials

When no `src` is provided, the avatar shows `initials` or a default user icon as fallback.

<ComponentShowcase>
  <div class="flex items-center gap-3">
    <RLAAvatar initials="JD" color="primary" />
    <RLAAvatar initials="AB" color="secondary" />
    <RLAAvatar initials="RL" color="success" />
    <RLAAvatar color="neutral" />
  </div>

<div slot="code-astro">
  ```astro
  <RLAAvatar initials="JD" color="primary" />
  <RLAAvatar initials="AB" color="secondary" />
  <RLAAvatar initials="RL" color="success" />
  <RLAAvatar color="neutral" />
  ```
</div>
</ComponentShowcase>

### Badge Indicator

Use the `badge` prop to show a status dot. Control its color with `badgeColor` and its placement with `badgePosition`.

<ComponentShowcase>
  <div class="flex items-center gap-4">
    <RLAAvatar src="https://i.pravatar.cc/150?img=1" alt="User 1" badge badgeColor="success" badgePosition="bottom-right" />
    <RLAAvatar src="https://i.pravatar.cc/150?img=2" alt="User 2" badge badgeColor="warning" badgePosition="top-right" />
    <RLAAvatar src="https://i.pravatar.cc/150?img=3" alt="User 3" badge badgeColor="error" badgePosition="bottom-left" />
    <RLAAvatar src="https://i.pravatar.cc/150?img=4" alt="User 4" badge={5} badgeColor="primary" badgePosition="top-left" />
  </div>

<div slot="code-astro">
  ```astro
  <RLAAvatar
    src="https://i.pravatar.cc/150?img=1"
    alt="User 1"
    badge
    badgeColor="success"
    badgePosition="bottom-right"
  />
  <RLAAvatar
    src="https://i.pravatar.cc/150?img=2"
    alt="User 2"
    badge
    badgeColor="warning"
    badgePosition="top-right"
  />
  <RLAAvatar
    src="https://i.pravatar.cc/150?img=3"
    alt="User 3"
    badge
    badgeColor="error"
    badgePosition="bottom-left"
  />
  <RLAAvatar
    src="https://i.pravatar.cc/150?img=4"
    alt="User 4"
    badge={5}
    badgeColor="primary"
    badgePosition="top-left"
  />
  ```
</div>
</ComponentShowcase>

### Badge Positions

Use the `badgePosition` prop to control where the badge is anchored on the avatar.

<ComponentShowcase
  togglingPattern="tab-segmented"
  componentName="RLAAvatar"
  propsConfig={{
    badgePosition: ["top-right", "top-left", "bottom-right", "bottom-left"]
  }}
  defaultProps={{
    badgePosition: "bottom-right"
  }}
>
  <RLAAvatar src="https://i.pravatar.cc/150?img=5" alt="User" badge badgeColor="success" />
</ComponentShowcase>

### Profile Layout

Provide `title` and `subtitle` props to render a horizontal profile card alongside the avatar.

  </div>

</ComponentShowcase>
