A full-width announcement bar designed to sit at the top of the page. Supports action links, a dismiss button, scroll-aware hiding, and stacking multiple banners via `stackIndex`.

## Usage

<ComponentShowcase>
  <RLABanner fixed={false} sticky={false}>We just launched v2.0 — check it out!</RLABanner>

  <div slot="code-astro">
    ```astro
    ---
    import RLABanner from "@rimelight/ui/components/astro/RLABanner.astro";
    ---

    <RLABanner>We just launched v2.0 — check it out!</RLABanner>
    ```

  </div>
</ComponentShowcase>

## Examples

### With Actions

Pass an `actions` array to render CTA links inside the banner. Each action accepts `label`, `href`, and `variant`.

<ComponentShowcase>
  <RLABanner
    fixed={false}
    sticky={false}
    actions={[
      { label: "Read More", href: "#", variant: "solid" },
      { label: "Dismiss", href: "#", variant: "ghost" }
    ]}
  >
    🎉 New features are now available.
  </RLABanner>

<div slot="code-astro">
  ```astro
  <RLABanner
    actions={[
      { label: "Read More", href: "/blog", variant: "solid" },
      { label: "Dismiss", href: "#", variant: "ghost" }
    ]}
  >
    🎉 New features are now available.
  </RLABanner>
  ```
</div>
</ComponentShowcase>

### Dismissable

Set `dismissable` to show a close button. Use `dismissId` to persist the dismissed state in localStorage so it stays hidden across page loads.

<ComponentShowcase>
  <RLABanner fixed={false} sticky={false} dismissable dismissId="launch-banner-demo">
    You can close this banner — it will remember your choice.
  </RLABanner>

<div slot="code-astro">
  ```astro
  <RLABanner dismissable dismissId="launch-banner-v1">
    You can close this banner — it will remember your choice.
  </RLABanner>
  ```
</div>
</ComponentShowcase>

### Left & Right Slots

Use the `left` and `right` named slots to place custom content on either side of the banner message.

<ComponentShowcase>
  <RLABanner fixed={false} sticky={false}>
    <span slot="left">🚀</span>
    Announcing our new product launch — explore what's new.
    <a slot="right" href="#" class="text-xs underline opacity-75 hover:opacity-100">Learn more</a>
  </RLABanner>

<div slot="code-astro">
  ```astro
  <RLABanner>
    <span slot="left">🚀</span>
    Announcing our new product launch — explore what's new.
    <a slot="right" href="/launch">
      Learn more
    </a>
  </RLABanner>
  ```
</div>
</ComponentShowcase>

### Fixed vs Sticky

By default banners are `fixed` to the top of the viewport. Set `fixed={false}` and `sticky` to make the banner stick when scrolled to.

<ComponentShowcase>
  <RLABanner fixed={false} sticky={false}>
    This banner renders inline (fixed=false, sticky=false).
  </RLABanner>

  <div slot="code-astro">
    ```astro
    <RLABanner>
      Always visible at the top of the page.
    </RLABanner>

    <RLABanner fixed={false} sticky>
      Sticks when you scroll to it.
    </RLABanner>

    <RLABanner fixed={false} sticky={false}>
      Renders in document flow.
    </RLABanner>
    ```

  </div>
</ComponentShowcase>
