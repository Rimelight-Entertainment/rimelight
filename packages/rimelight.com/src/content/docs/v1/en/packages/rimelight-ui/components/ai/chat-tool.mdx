The ChatTool component wraps rendering blocks for agent tool calls, showing function parameters and return values.

## Usage

Use the ChatTool component to format AI tool use events.

<ComponentShowcase>
  <RLAChatTool class="border rounded-md p-3 bg-muted/50 flex flex-col gap-2 max-w-md">
    <div class="flex items-center gap-2 text-xs font-semibold text-primary">
      <span class="i-lucide-wrench size-3.5"></span>
      <span>CALLING TOOL: <code>get_weather</code></span>
    </div>
    <div class="text-xs font-mono bg-muted p-2 rounded">
      {"{"} "location": "San Francisco, CA" {"}"}
    </div>
  </RLAChatTool>
