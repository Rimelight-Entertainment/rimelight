A component that allows users to select a single option from a set of mutually exclusive choices.

## Usage

How to use the Radio Group component in its simplest form.

<ComponentShowcase>
  <RLARadioGroup class="flex flex-col gap-2">
    <label class="flex items-center gap-2 text-sm cursor-pointer">
      <input type="radio" name="options" value="1" />
      Option 1
    </label>
    <label class="flex items-center gap-2 text-sm cursor-pointer">
      <input type="radio" name="options" value="2" />
      Option 2
    </label>
  </RLARadioGroup>

  <div slot="code-astro">
