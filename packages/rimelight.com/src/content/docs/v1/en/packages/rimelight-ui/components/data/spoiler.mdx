The Spoiler component hides text or images with a blur or dark background until hovered, focused, or clicked.

## Usage

Wrap the text you want to hide in the Spoiler component. You can toggle visibility by using Tailwind's interactive state utilities (e.g. blur classes that vanish on hover/click).

<ComponentShowcase>

  </p>
