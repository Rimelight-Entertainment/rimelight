The `TableOfContents` component parses a list of headings and outputs an active-tracked sidebar outline. It also supports a collapsible mobile layout.

## Usage

<ComponentShowcase>
  <RLATableOfContents
    headings={[
      { depth: 2, slug: "usage", text: "Usage" },
      { depth: 2, slug: "examples", text: "Examples" },
      { depth: 3, slug: "collapsible-example", text: "Collapsible Example" }
    ]}
  />

  <div slot="code-astro">
    ```astro
    ---
    import RLATableOfContents from "@rimelight/ui/components/table-of-contents/RLATableOfContents.astro";

    const headings = [
      { depth: 2, slug: "usage", text: "Usage" },
      { depth: 2, slug: "examples", text: "Examples" },
      { depth: 3, slug: "collapsible-example", text: "Collapsible Example" }
    ];
    ---

    <RLATableOfContents headings={headings} />
    ```

  </div>
</ComponentShowcase>

## Examples

### Collapsible Mode

Set the `collapsible` prop to true to render the TOC inside a details disclosure button, ideal for mobile header structures.

<ComponentShowcase>
  <RLATableOfContents
    collapsible
    headings={[
      { depth: 2, slug: "usage", text: "Usage" },
      { depth: 2, slug: "examples", text: "Examples" }
    ]}
  />

  <div slot="code-astro">
    ```astro
    <RLATableOfContents
      collapsible
      headings={[
        { depth: 2, slug: "usage", text: "Usage" },
        { depth: 2, slug: "examples", text: "Examples" }
      ]}
    />
    ```
  </div>
</ComponentShowcase>
