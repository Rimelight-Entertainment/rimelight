A dropdown select input component for choosing options from a list.

## Usage

How to use the Select component in its simplest form.

<ComponentShowcase>
  <RLASelect items={["Option 1", "Option 2", "Option 3"]} placeholder="Choose an option..." />

  <div slot="code-astro">
    ```astro
    ---
    import RLASelect from "@rimelight/ui/components/select/RLASelect.astro";
    ---

    <RLASelect items={["Option 1", "Option 2", "Option 3"]} placeholder="Choose an option..." />
    ```

  </div>
</ComponentShowcase>

## Examples

### With Label

Add a label to describe the select dropdown.

<ComponentShowcase>
  <RLASelect
    label="Choose your role"
    items={["Admin", "User", "Guest"]}
    placeholder="Select a role..."
  />

  <div slot="code-astro">
    ```astro
    ---
    import RLASelect from "@rimelight/ui/components/select/RLASelect.astro";
    ---

    <RLASelect
      label="Choose your role"
      items={["Admin", "User", "Guest"]}
      placeholder="Select a role..."
    />
    ```

  </div>
</ComponentShowcase>

### Disabled

Use the `disabled` prop to prevent interaction.

<ComponentShowcase>
  <RLASelect

  />

  <div slot="code-astro">
    ```astro

      disabled
      items={["Admin", "User", "Guest"]}
      placeholder="Select a role..."
    />
    ```

  </div>
</ComponentShowcase>
