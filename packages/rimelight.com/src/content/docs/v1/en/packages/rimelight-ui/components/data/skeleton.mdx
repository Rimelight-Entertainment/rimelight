The Skeleton component displays a pulse animation placeholder, useful when loading text, images, or cards to reduce perceived latency.

## Usage

Use the Skeleton component to design a loading layout matching your actual content structure.

<ComponentShowcase>
  <div class="flex items-center gap-4 w-full max-w-sm">
    <RLASkeleton shape="circle" class="size-12" />
    <div class="flex-1 space-y-2">
      <RLASkeleton shape="rounded" class="h-4 w-3/4" />
      <RLASkeleton shape="rounded" class="h-3 w-1/2" />
    </div>
  </div>

  <div slot="code-astro">
    ```astro
    ---
    import RLASkeleton from "@rimelight/ui/components/astro/RLASkeleton.astro";
    ---

    <div class="flex items-center gap-4 w-full max-w-sm">
      <RLASkeleton shape="circle" class="size-12" />
      <div class="flex-1 space-y-2">
        <RLASkeleton shape="rounded" class="h-4 w-3/4" />
        <RLASkeleton shape="rounded" class="h-3 w-1/2" />
      </div>
    </div>
    ```

  </div>
</ComponentShowcase>

## Examples

### Shapes

Use the `shape` prop to change the corner radius of the skeleton element. Supported shapes are `circle`, `rounded` (default), and `rectangle`.

<ComponentShowcase>
  <div class="flex items-center gap-6 w-full">
    <div class="flex flex-col items-center gap-2">
      <RLASkeleton shape="circle" class="size-16" />
      <span class="text-xs text-muted-foreground">circle</span>
    </div>
    <div class="flex flex-col items-center gap-2">
      <RLASkeleton shape="rounded" class="size-16" />
      <span class="text-xs text-muted-foreground">rounded</span>
    </div>
    <div class="flex flex-col items-center gap-2">
      <RLASkeleton shape="rectangle" class="size-16" />
      <span class="text-xs text-muted-foreground">rectangle</span>
    </div>
  </div>

  <div slot="code-astro">
    ```astro
    ---
    import RLASkeleton from "@rimelight/ui/components/astro/RLASkeleton.astro";
    ---

    <RLASkeleton shape="rounded" class="size-16" />
    <RLASkeleton shape="rectangle" class="size-16" />
    ```

  </div>
</ComponentShowcase>
