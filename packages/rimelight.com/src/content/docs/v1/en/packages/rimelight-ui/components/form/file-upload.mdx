## Examples

### Accept Specific Types

Use the `accept` prop to restrict uploaded file types.

<ComponentShowcase>
  <RLAFileUpload accept=".pdf,.docx" description="PDF and DOCX only" />

  <div slot="code-astro">
    ```astro
    ---
    import RLAFileUpload from "@rimelight/ui/components/astro/RLAFileUpload.astro";
    ---

    <RLAFileUpload accept=".pdf,.docx" description="PDF and DOCX only" />
    ```

  </div>
</ComponentShowcase>
