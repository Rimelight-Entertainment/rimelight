The Window Mockup component allows you to wrap content in a generic operating system window shell, complete with control buttons (close, minimize, maximize) on the title bar.

## Usage

How to use the Window Mockup component in its simplest form.

<ComponentShowcase>
  <RLAWindowMockup class="border border-border rounded-lg overflow-hidden shadow-lg">
    <div class="p-8 bg-neutral-50 dark:bg-neutral-900 text-center">
      <h3 class="text-lg font-bold">App Window</h3>
      <p class="text-sm text-muted-foreground mt-2">This content is hosted inside an OS-style window frame.</p>
    </div>
  </RLAWindowMockup>

  <div slot="code-astro">
    ```astro
    ---
    import RLAWindowMockup from "@rimelight/ui/components/window-mockup/RLAWindowMockup.astro";
    ---

    <RLAWindowMockup class="border border-border rounded-lg overflow-hidden shadow-lg">
      <div class="p-8 bg-neutral-50 dark:bg-neutral-900 text-center">
        <h3 class="text-lg font-bold">App Window</h3>
        <p class="text-sm text-muted-foreground mt-2">This content is hosted inside an OS-style window frame.</p>
      </div>
    </RLAWindowMockup>
    ```

  </div>
</ComponentShowcase>
