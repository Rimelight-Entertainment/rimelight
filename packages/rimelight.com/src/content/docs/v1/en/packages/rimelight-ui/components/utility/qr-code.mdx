The QR Code component is a styled container wrapper designed to hold and present QR code images or vectors nicely within your UI layouts.

## Usage

How to use the QR Code component wrapper to present a QR code image.

<ComponentShowcase>
  <div class="flex justify-center">
    <RLAQrCode class="p-4 bg-white border border-border rounded-xl shadow-sm w-fit">
      <img src="https://api.qrserver.com/v1/create-qr-code/?size=150x150&data=https://rimelight.com" alt="QR Code" width="150" height="150" />
    </RLAQrCode>
  </div>

  <div slot="code-astro">
    ```astro
    ---
    import RLAQrCode from "@rimelight/ui/components/astro/RLAQrCode.astro";
    ---

    <RLAQrCode class="p-4 bg-white border border-border rounded-xl shadow-sm w-fit">
      <img src="https://api.qrserver.com/v1/create-qr-code/?size=150x150&data=https://rimelight.com" alt="QR Code" width="150" height="150" />
    </RLAQrCode>
    ```

  </div>
</ComponentShowcase>
