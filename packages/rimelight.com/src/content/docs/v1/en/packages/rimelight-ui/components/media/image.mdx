The Image component renders an optimized image that opens a metadata-rich lightbox modal when clicked. It supports native Astro image optimization, responsive source switching, and user-initiated downloads.

## Usage

How to use the Image component in its simplest form.

<ComponentShowcase>
  <div class="max-w-sm">
    <RLAImage src="https://images.unsplash.com/photo-1579546929518-9e396f3cc809" alt="Colorful gradient" />
  </div>

  <div slot="code-astro">
    ```astro
    ---

    ---

    <div class="max-w-sm">
      <RLAImage src="https://images.unsplash.com/photo-1579546929518-9e396f3cc809" alt="Colorful gradient" />
    </div>
    ```

  </div>
</ComponentShowcase>

## Examples

### Hiding Metadata

You can disable specific pieces of metadata in the lightbox using the `meta*` boolean props.

<ComponentShowcase>
  <div class="max-w-sm">
    <RLAImage
      src="https://images.unsplash.com/photo-1579546929518-9e396f3cc809"
      alt="Colorful gradient"
      metaSource={false}
      metaDimensions={false}
      metaDownload={false}
    />
  </div>

  <div slot="code-astro">
    ```astro
    ---
    import RLAImage from "@rimelight/ui/components/astro/RLAImage.astro";
    ---

    <RLAImage
      src="https://images.unsplash.com/photo-1579546929518-9e396f3cc809"
      alt="Colorful gradient"
      metaSource={false}
      metaDimensions={false}
      metaDownload={false}
    />
    ```

  </div>
</ComponentShowcase>
