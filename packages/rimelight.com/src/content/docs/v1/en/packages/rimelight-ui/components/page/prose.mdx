The `Prose` component automatically styles headings, paragraphs, links, quotes, and lists inside it, which is ideal for rendering markdown articles or rich text content.

## Usage

<ComponentShowcase>
  <RLAProse>
    <h1>This is a heading</h1>
    <p>This is a paragraph with some <strong>bold</strong> text and a <a href="#">link</a>.</p>
    <ul>
      <li>First bullet</li>
      <li>Second bullet</li>
    </ul>
  </RLAProse>

  <div slot="code-astro">

  </div>
</ComponentShowcase>
