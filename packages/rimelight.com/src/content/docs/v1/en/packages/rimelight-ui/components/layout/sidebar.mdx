A Sidebar layout component providing vertical navigation, support for active states, badges, collapsed states, and icons.

## Usage

How to use the Sidebar component in its simplest form.

<ComponentShowcase>
  <RLASidebar
    logo="My Project"
    items={[
      { label: "Home", href: "#", icon: "i-lucide-home", active: true },
      { label: "Dashboard", href: "#", icon: "i-lucide-layout-dashboard" },
      { label: "Settings", href: "#", icon: "i-lucide-settings" }
    ]}
  />

  <div slot="code-astro">
    ```astro
    ---
    import RLASidebar from "@rimelight/ui/components/sidebar/RLASidebar.astro";

    const navItems = [
      { label: "Home", href: "#", icon: "i-lucide-home", active: true },
      { label: "Dashboard", href: "#", icon: "i-lucide-layout-dashboard" },
      { label: "Settings", href: "#", icon: "i-lucide-settings" }
    ];
    ---

    <RLASidebar logo="My Project" items={navItems} />
    ```

  </div>
</ComponentShowcase>

## Examples

### Nested Items

The Sidebar supports nested list items for hierarchical navigation.

<ComponentShowcase>
  <RLASidebar
    items={[
      {
        label: "Resources",
        icon: "i-lucide-folder",
        children: [
          { label: "Guides", href: "#", icon: "i-lucide-book" },
          { label: "API Reference", href: "#", icon: "i-lucide-code" }
        ]
      }
    ]}
  />

  <div slot="code-astro">
    ```astro
    ---
    import RLASidebar from "@rimelight/ui/components/sidebar/RLASidebar.astro";

    const navItems = [
      {
        label: "Resources",
        icon: "i-lucide-folder",
        children: [
          { label: "Guides", href: "#", icon: "i-lucide-book" },
          { label: "API Reference", href: "#", icon: "i-lucide-code" }
        ]
      }
    ];
    ---

    <RLASidebar items={navItems} />
    ```

  </div>
</ComponentShowcase>
