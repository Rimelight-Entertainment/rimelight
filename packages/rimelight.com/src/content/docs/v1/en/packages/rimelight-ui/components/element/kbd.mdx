The `Kbd` component renders keyboard shortcuts or hotkeys with custom sizing, coloring, and border styling.

## Usage

<ComponentShowcase>
  <RLAKbd>⌘ K</RLAKbd>

  <div slot="code-astro">
    ```astro
    ---
    import RLAKbd from "@rimelight/ui/components/kbd/RLAKbd.astro";
    ---

    <RLAKbd>⌘ K</RLAKbd>
    ```

  </div>
</ComponentShowcase>

## Examples

### Sizes

Use the `size` prop to change the size of the keyboard indicator.

<ComponentShowcase>
  <div class="flex items-center gap-2">
    <RLAKbd size="sm">Ctrl</RLAKbd>
    <RLAKbd size="md">Ctrl</RLAKbd>
    <RLAKbd size="lg">Ctrl</RLAKbd>
  </div>

  <div slot="code-astro">
    ```astro
    <RLAKbd size="sm">Ctrl</RLAKbd>
    <RLAKbd size="md">Ctrl</RLAKbd>
    <RLAKbd size="lg">Ctrl</RLAKbd>
    ```
  </div>
</ComponentShowcase>

### Variants

Use the `variant` prop to adjust the visual appearance.

<ComponentShowcase>
  <div class="flex items-center gap-2">
    <RLAKbd variant="solid">Alt</RLAKbd>
    <RLAKbd variant="outline">Shift</RLAKbd>
  </div>

  <div slot="code-astro">
    ```astro
    <RLAKbd variant="solid">Alt</RLAKbd>
    <RLAKbd variant="outline">Shift</RLAKbd>
    ```
  </div>
</ComponentShowcase>
