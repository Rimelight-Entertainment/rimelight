## Deployment Platform

rimelight.com is deployed on [Cloudflare Workers](https://workers.cloudflare.com).

## Deployment Process

1. **Continuous Integration / Continuous Deployment (CI/CD)**: Any changes pushed to the `main` branch are automatically built and deployed by [Cloudflare Workers Builds](https://developers.cloudflare.com/workers/ci-cd/).
2. **Preview Deployments**: Pull requests and other branches also trigger preview deployments.

## Configuration

The deployment is configured via two configuration files:

```ts
// astro.config.ts
import cloudflare from "@astrojs/cloudflare"
import { defineConfig } from "astro/config"

export default defineConfig({
  output: "server",
  adapter: cloudflare()
})
```

```
// wrangler.jsonc
{
  "$schema": "node_modules/wrangler/config-schema.json",
  "name": "rimelight-dot-com",
  "main": "@astrojs/cloudflare/entrypoints/server",
  "compatibility_date": "2026-04-12",
  "compatibility_flags": ["global_fetch_strictly_public", "nodejs_compat"],
}
```

## Manual Build

To build the project locally, run:

```bash
pnpm run build
```

The output will be in the `dist/` directory, and can be previewed using:

```bash
pnpm run preview
```
