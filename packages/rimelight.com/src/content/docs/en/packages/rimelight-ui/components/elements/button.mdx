A versatile button component with support for multiple variants, colors, and sizes.

## Usage

<ComponentShowcase>
  <RLAButton label="Click me" />

  <Fragment slot="code-astro">
  ```astro
  <RLAButton label="Click me" />
  ```
  </Fragment>

  <Fragment slot="code-vue">
  ```vue
  <RLVButton label="Click me" />
  ```
  </Fragment>
</ComponentShowcase>
