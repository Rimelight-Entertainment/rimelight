`AvatarGroup` is a wrapper that stacks multiple `Avatar` components in an overlapping horizontal layout. Ideal for showing a compact list of collaborators, participants, or team members.

## Usage

<ComponentShowcase>
  <RLAAvatarGroup>
    <RLAAvatar src="https://i.pravatar.cc/150?img=1" alt="User 1" />
    <RLAAvatar src="https://i.pravatar.cc/150?img=2" alt="User 2" />
    <RLAAvatar src="https://i.pravatar.cc/150?img=3" alt="User 3" />
  </RLAAvatarGroup>

  <div slot="code-astro">
    ```astro
    ---
    import RLAAvatarGroup from "@rimelight/ui/components/astro/RLAAvatarGroup.astro";
    import RLAAvatar from "@rimelight/ui/components/astro/RLAAvatar.astro";
    ---

    <RLAAvatarGroup>
      <RLAAvatar src="https://i.pravatar.cc/150?img=1" alt="User 1" />
      <RLAAvatar src="https://i.pravatar.cc/150?img=2" alt="User 2" />
      <RLAAvatar src="https://i.pravatar.cc/150?img=3" alt="User 3" />
    </RLAAvatarGroup>
    ```

  </div>

  <div slot="code-vue">
