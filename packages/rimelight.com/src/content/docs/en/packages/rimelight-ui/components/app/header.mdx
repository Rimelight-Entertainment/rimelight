The Header component provides a unified structural shell for application and website navigation. Built with a robust CSS-first architecture, it handles fixed positioning, dynamic z-indexing, and multiple-layer stacking automatically using a lightweight vanilla JS stack manager.

It is available as a native Astro component (`RLAHeader`) for static/island architectures and a Vue component (`RLVHeader`) for highly interactive single-page apps.

### Dynamic Stacking

A core feature of the Rimelight Header is its ability to elegantly stack multiple fixed headers on top of each other.

By passing `fixed={true}` and assigning a sequential `stackIndex` (e.g., `0` for the top-most header, `1` for the one below it), the components will register with the global `RLHeaderStack` manager. This manager dynamically calculates offsets and synchronizes visibility states across boundaries—meaning an Astro header and a Vue header can stack perfectly together on the same page.

### Scroll Hide

Passing `hideOnScroll={true}` attaches a highly optimized, passive scroll listener to the header. When the user scrolls down, the header seamlessly slides up and out of view. When they scroll back up, it slides down.

If you have multiple stacked headers, hiding a layer will cause all layers beneath it to smoothly slide up and fill the gap!
