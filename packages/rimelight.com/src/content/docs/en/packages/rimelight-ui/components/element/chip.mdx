A small dot or counter that overlays a target element to indicate status, notifications, or counts. Can also be used `standalone` without wrapping any content.

## Usage

<ComponentShowcase>
  <RLAChip text="99+" standalone />

  <div slot="code-astro">
    ```astro
    ---
    import RLAChip from "@rimelight/ui/components/astro/RLAChip.astro";
    ---

    <RLAChip text="99+" standalone />
    ```

  </div>

  <div slot="code-vue">
    ```vue
    <script setup>
    import RLVChip from "@rimelight/ui/components/vue/RLVChip.vue";
    </script>

    <template>
      <RLVChip text="99+" :standalone="true" />
    </template>
    ```

  </div>
</ComponentShowcase>
