Rimelight UI provides built-in support for dark and light modes, leveraging **UnoCSS**'s class-based dark mode strategy.

## Class Strategy

By default, Rimelight UI uses the `.dark` class on the `<html>` or `<body>` element to toggle dark mode styles.

```html
<!-- Light Mode -->
<html>
  ...
</html>

<!-- Dark Mode -->
<html class="dark">
  ...
</html>
```

## Styling Components

Every Rimelight UI component is built to be color-mode aware. When you use semantic colors like `primary` or `neutral`, the component automatically swaps its color palette when the `.dark` class is present.

### Custom Dark Styles

If you need to apply specific dark-mode-only classes in your own templates, use the `dark:` variant from UnoCSS:

```html
<div class="bg-white text-black dark:bg-black dark:text-white">
  This content adapts to the color mode.
</div>
```

## Toggle Implementation

While Rimelight UI doesn't provide a standalone toggle component yet (it's planned as a native component), you can implement one easily using a small piece of JavaScript or by using the re-exported `Button` with custom logic.

```astro
<script is:inline>
  const theme = (() => {
    if (typeof localStorage !== 'undefined' && localStorage.getItem('theme')) {
      return localStorage.getItem('theme');
    }
    if (window.matchMedia('(prefers-color-scheme: dark)').matches) {
      return 'dark';
    }
    return 'light';
  })();

  if (theme === 'light') {
    document.documentElement.classList.remove('dark');
  } else {
    document.documentElement.classList.add('dark');
  }
</script>
```

## System Preference

Rimelight UI respects the user's system preference by default if no explicit theme is stored in the browser's local storage.
