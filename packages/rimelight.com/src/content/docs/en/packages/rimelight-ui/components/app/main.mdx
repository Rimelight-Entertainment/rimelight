A semantic &lt;main&gt; element that fills the viewport height.

## Usage

The Main component renders a `<main>` element that works in conjunction with the [Header](http://rimelight.com/en/docs/packages/rimelight-ui/components/app/header) component to create a full-height layout that extends to the viewport's available height.
