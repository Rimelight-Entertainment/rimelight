A button element that can be used to trigger actions or navigate to other pages. Supports icons, loading states, avatar, link mode, and full theme customization.

## Usage

<ComponentShowcase>
  <RLAButton label="Button" />

  <div slot="code-astro">
    ```astro
    ---
    import RLAButton from "@rimelight/ui/components/astro/RLAButton.astro";
    ---

    <RLAButton label="Button" />
    ```

  </div>

  <div slot="code-vue">
    ```vue
    <script setup>
    import RLVButton from "@rimelight/ui/components/vue/RLVButton.vue";
    </script>

    <template>
      <RLVButton label="Button" />
    </template>
    ```

  </div>
</ComponentShowcase>
