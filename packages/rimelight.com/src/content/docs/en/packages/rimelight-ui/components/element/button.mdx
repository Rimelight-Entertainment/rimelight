A button element that can be used to trigger actions or navigate to other pages.

## Usage

<ComponentShowcase>
  <RLAButton label="Click me" />
  <div slot="code-astro">
    ```astro
    ---
    import RLAButton from "@rimelight/ui/components/astro/RLAButton.astro";
    ---

    <RLAButton label="Click me" />
    ```

  </div>

  <div slot="code-vue">
    ```vue
    <script setup>
    import RLVButton from "@rimelight/ui/components/vue/RLVButton.vue";
    </script>

    <template>
      <RLVButton label="Click me" />
    </template>
    ```

  </div>
</ComponentShowcase>

## Examples

### Variants

Use the `variant` prop to change the variant of the button.

    <RLAButton variant="subtle" color="primary">Subtle</RLAButton>
    <RLAButton variant="ghost" color="primary">Ghost</RLAButton>

  </div>

  <div slot="code-astro">
