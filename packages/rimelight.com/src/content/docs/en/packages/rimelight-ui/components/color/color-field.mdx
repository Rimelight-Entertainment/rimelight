The Color Field component provides an input for editing and entering hexadecimal or specific channel color values. It features a built-in color swatch block to visualize the active selection.

## Anatomy

Import the component and use it directly:

```astro
---
import RLAColorField from "@rimelight/ui/components/astro/RLAColorField.astro"
---

<RLAColorField defaultValue="#10b981" />
```
