---
title: "useToast"
description: "A composable to display toast notifications in your app."
---

The `useToast` composable allows you to programmatically trigger toast notifications from anywhere in your Vue components or interactive Astro pages.

:::note[Nuxt UI Re-export]
The `useToast` composable is currently a re-export from [Nuxt UI](https://ui.nuxt.com/docs/composables/use-toast).
:::

## Usage

Import `useToast` and call it to get access to the toast API.

```vue
<script setup lang="ts">
import { useToast } from "@rimelight/ui/nuxt"

const toast = useToast()

function notify() {
  toast.add({
    title: "Notification",
    description: "This is a toast message.",
    color: "success",
    icon: "i-lucide-check"
  })
}
</script>

<template>
  <button @click="notify">Show Toast</button>
</template>
```

## API Reference

### `add(options)`

Adds a new toast to the queue.

| Option        | Type     | Description                                        |
| :------------ | :------- | :------------------------------------------------- |
| `title`       | `string` | The title of the toast.                            |
| `description` | `string` | The detailed message.                              |
| `color`       | `string` | The color variant (primary, success, error, etc.). |
| `icon`        | `string` | An icon name.                                      |
| `duration`    | `number` | Time in ms before auto-closing.                    |
| `actions`     | `array`  | Action buttons to display.                         |

### `remove(id)`

Removes a specific toast by its ID.

### `clear()`

Removes all active toasts.
