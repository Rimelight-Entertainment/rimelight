Scope: Media's `ui/tokens.slint`, `ui/widgets.slint`, `ui/icons.slint`, `ui/app.slint` and the page files in `ui/`, compared with Space's generated `crates/rimelight_ui/ui/generated/tokens.slint` and `crates/rimelight_ui/ui/components/`. Read-only audit. Line numbers are the file's own lines.

Sources, by short name:

- Media tokens: `C:\Users\idant\RustRoverProjects\rimelight-media\ui\tokens.slint`

Drift key: `same` = same light and dark value. `different` = matched by name or meaning, values differ. `Media-only` = no Space token with the same or a nearest meaning. The "Space token" column is the match used; where Media's name differs from Space's (e.g. `control-height` vs `size-control-height`), the mapping is noted in the Space column.

Note on Space values: Space's generated file marks dark-mode values with `dark ? X : Y`; the table shows the light value (`Y`) and dark value (`X`). Where Space's value is written with `* zoom-factor`, the zoom factor is dropped (it is 1.0 at 100 per cent in both).

Notes on the token diff:

- Media has no `reduced-motion`, `text-scale-percent` or `zoom-percent` (Space has all three, Space lines 16-21). Media has no interface zoom, so every Media length is a fixed pixel value.
- Media's `surface-hover` (`ui/tokens.slint:15`) and `surface-pressed` (`:16`) are used by every hover and pressed state in `widgets.slint`. Space's generated file has no `surface-hover` or `surface-pressed` (the Space components use other names; not checked further). This is the largest semantic gap.
- Media `Type.heading` (20px) and `Type.title` (28px) differ from Space's `type-heading-size` (22px) and `type-title-size` (26px). Media's `Type.family` is the Windows UI face "Segoe UI Variable Text" (`:80`); Space uses Noto Sans for every role. Media `Type` has no line heights, no weights and no code face; Space has all of them.
- Media's `icon-large` is 28px (`:74`); Space's `size-icon-large` is 24px (`:169`).
- Media's `control-height` is 32px (`:67`); Space's `size-control-height` is 34px (`:141`).
- Media has none of Space's `button-*`, `tooltip-*`, `rail-*`, `sidebar-*` or `disabled-*` tokens. Media's buttons are drawn from the semantic colours directly in `widgets.slint` (see section 3).
- Media-only layout tokens (`top-section`, `row-height`, `bar-height`, `action-height`, `status-height`) have no Space equivalent. Space's closest sizes are `size-tab-bar-height` (56px, `:163`), `size-tree-row-height` (30px, `:165`) and `size-menu-row-height` (28px, `:166`). They are different meanings, so they are marked Media-only.
- Media's `stage` (`:18`, `#0A0C10` dark / `#1B1E24` light) and `text-on-stage` (`:23`) are the picture and video viewer colours. Space has no equivalent.
- Media's `file-picture`, `file-video`, `file-music`, `file-text` (`:43-46`) are the Explorer file-type colours from `src/install.rs`. Space has none.
- Media's `selection`, `scrim` and `status-*-surface` values are identical to Space's (see table).
- Media's `surface-sunken` light value is `#E8EDF3` (`:13`); Space's is `#F3F9FF` (Space `:27`). It is the only surface difference.
- Media's `accent-hover` light is `#0968DA` (`:27`), the same as Space. Media's `accent-fill` light is `#1659C4` (`:29`), the same as Space. Both match.
- Media's `radius-r8` (`:55`), `radius-pill` (`:56`), `radius-control` (`:48`) and `radius-surface` (`:49`) match Space's values. Media has no `radius-r4`, `radius-r6`, `radius-none`.

## 6. Layout conventions (as seen in the markup)

- Tab shell: each tab is a ToolBar on top, the page body, and a StatusBar at the bottom. The toolbar and status bar are hidden in full screen (`app.slint:72` `if !Shell.full-screen: ToolBar`; `image_page.slint:152` and `:927`; `text_page.slint` and `media_page.slint` use the same flag). Audio and Video use `MediaSlot` (`app.slint:63-122`), which shows the player or the EmptyState depending on what is loaded.
- Top bar (`ToolBar`, `widgets.slint:469-483`): 44px, surface-raised, 1px bottom border. Left: file actions (Open, Show in folder), a ToolDivider, save and share, a ToolDivider, undo, redo, discard, then a spacer, then the mode buttons and close on the right (`app.slint:72-94`; `image_page.slint:152-205`; `text_page.slint:305-357`; `camera_page.slint:21-64`; `voice_page.slint:15-65`). Groups are separated by `ToolDivider` (`widgets.slint:582-592`). Each toolbar button is an `IconButton` whose `label` is its tooltip. Buttons that need an open file are `enabled: false` when nothing is open (`app.slint:76-93`; `image_page.slint:154-160`).
- Edit row (`ActionRow`, `widgets.slint:488-519`): 44px, surface-base, 1px bottom border, the same height on every tab. Used for crop (`image_page.slint:207`), resize (`:231`), markup (`:268`), trim (`media_page.slint:408`), JSON tools (`text_page.slint:364`) and find and replace (`text_page.slint:383`). Left side holds icon buttons or fields; confirm and cancel sit at the far right when `show-confirm` is set.
- Status bar (`StatusBar`, `widgets.slint:529-579`): 36px, surface-raised, 1px top border, caption-size muted text on the left (file facts), optional centre text, and children on the right. The shortcuts button (28px, `Icons.keyboard`) is pinned to the right edge (`widgets.slint:569-577`), and the row reserves room for it. The image tab's status bar has 28px Details, Filmstrip and Slideshow buttons on the left and frame and zoom controls on the right (`image_page.slint:927-935`). The text tab has a Details button and the saved state in one row (`text_page.slint:463-470`). Empty tabs: `StatusBar { left-text: ""; }` (`app.slint:117-120`); Home (`home.slint:25`).
- Dialogs: `ConfirmDialog` (`widgets.slint:416-459`) is a full-window scrim with a centred card, 420px wide or window width minus 48px, radius 8px. `AppWindow` hosts it above everything, including the top bar (`app.slint:305-315`). Button order: Cancel at the left (ghost); Don't save then Save at the right. The shortcuts overlay is also a window-level overlay (`app.slint:317-323`; `shortcuts.slint:68`). Toast: a pill 40px high, radius 20px, 96px above the bottom edge (`app.slint:289-292`). The cast popup is a PopupWindow under the cast button, 300px wide (`app.slint:146`; `cast_popup.slint:8`).
- Popups: `ChoicePopup` (`widgets.slint:308-360`) and the IconButton tooltip (`:99-120`); radius 8px, subtle border, literal 16px shadow.
- Empty states (`EmptyState`, `widgets.slint:668-772`): a ScrollView with a centred column (max 640px). The top section is a fixed 300px (`widgets.slint:710`, `Tokens.top-section`) and holds: the 56px file tile or icon (`:714-719`), a 40px title line in `Type.title` (`:720-728`), a fixed 88px block with "Supported file types:" and the list or a hint (`:730-737`), and the Open and New buttons in a control-height row (`:738-756`). Below it, `RecentBlock` (`:758-767`, defined `:634-666`): a 32px header with Clear, then a card with 48px rows or the placeholder line. Used by the Image tab (`image_page.slint:840`), Audio and Video (`app.slint:99-116`), Text (`text_page.slint:418`) and Home (`home.slint:13-24`).
- Cards: Settings sections (`settings_page.slint:8-16`: title in `Type.heading`, detail in caption, `space-2` spacing) use `Card` (`settings_page.slint:129, 160, 194, 208`). Voice uses `Card` for markers and takes (`voice_page.slint:83, 165, 181`).
- Window: preferred 1200 x 780, min 640 x 420 (`app.slint:127-130`). The nav rail is on the left (`app.slint:174-208`): Home, Image, Audio, Video, Text; then Record, Voice, Camera, New text, Cast; Settings at the bottom.
- Spacing scale used: 4, 8, 12, 16, 20, 24, 32, 40 px (`tokens.slint:58-65`). Space also has 0 and 48. Media has no zoom or text scale, so every value is fixed.
