## What is LLMs.txt?

`llms.txt` is a structured documentation format specifically designed for large language models (LLMs). Rimelight UI provides these files to help AI tools like Cursor, Windsurf, and GitHub Copilot understand our component library, dual-engine architecture, and styling patterns.

## Available Files

We provide specialized routes optimized for AI consumption:

- **`/llms.txt`**: A structured overview of all components, core concepts, and documentation links.
- **`/llms-full.txt`**: Comprehensive documentation including full implementation details, examples, and theming guides.

## Usage with AI Tools

### Cursor & Windsurf

You can reference these files directly in your AI chat or by adding them to your project's documentation context using the `@` symbol.

1. Type `@docs` in your chat interface.
2. Add `https://rimelight.com/llms.txt`.
3. Ask questions like "How do I create a themed RLAButton?" or "What's the difference between RLA and RLV components?".

### GitHub Copilot & ChatGPT

You can provide the URL directly in your prompt to give the model updated context:

> "Use the documentation at https://rimelight.com/llms.txt to help me build a dashboard layout with Rimelight UI."

## Benefits

- **Up-to-date Context**: AI models often have a training cutoff. `llms.txt` provides the latest API details.
- **Architecture Awareness**: Helps models distinguish between Astro (Server) and Vue (Client) components.
- **Consistent Styling**: Ensures the AI suggests valid UnoCSS classes and theme overrides.
