## What is Rimelight UI?

Rimelight UI is a comprehensive component library for [Astro](https://astro.build) websites used and maintained by [Rimelight Entertainment](https://rimelight.com).
It offers a suite of accessible and highly performant components as [Astro Components](https://docs.astro.build/basics/astro-components/) and [Vue Components](https://vuejs.org), and is available as a free and open source project for any to use.

## Performance

- All dependencies used have zero sub-dependencies, ensuring a lean and efficient bundle size.
- All components are fully [type-safe](https://www.typescriptlang.org) and fully [SEO-friendly](https://web.dev/seo-checklist/).
- All components use [UnoCSS](https://unocss.dev) for on-demand Atomic CSS and [CSS Variants](https://css-variants.vercel.app) for performant slot styling and customizability.

## Accessibility

- All components are fully [WCAG 2.1](https://www.w3.org/TR/WCAG21/)-compliant with [WAI-ARIA](https://www.w3.org/WAI/standards-guidelines/aria/) attributes, keyboard navigation, focus management, and screen reader support out of the box.
- All components support automatic [light and dark mode](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/light-dark) alongside easy overriding for instances where ignoring color mode may be desired (e.g. highly branded sections).
- All components follow [semantic HTML](https://developer.mozilla.org/en-US/docs/Glossary/Semantics) fully [SEO-friendly](https://web.dev/seo-checklist/) and follow best practices for accessibility.

## Frequently Asked Questions

<details>
  <summary>Is Rimelight UI free to use?</summary>
  Yes. Rimelight UI is a completely free and open source package under the [MIT
  License](https://opensource.org/license/mit).
</details>

<details>
  <summary>Can I use Rimelight UI without Astro?</summary>
  For the time being, no. The library is strictly distributed as an Astro integration, but in theory
  could be modularized enough to be usable as a Vite plugin, and we are open to contributions on
  this topic.
</details>

<details>
  <summary>Are other front-end frameworks supported?</summary>
  For the time being, no. The library currently only offers Astro and Vue components, but in theory
  could support other front-end frameworks, and we are open to contributions on this topic.
</details>

<details>
  <summary>Is Rimelight UI customizable?</summary>
  All components can have their styles overridden per slot and per variant, either globally or per
  instance, but their basic structure is fixed.
</details>

<details>
  <summary>Is Rimelight UI accessible?</summary>
  All components provide automatic ARIA attributes, keyboard navigation, focus management, and
  screen reader support. We offer an accessible foundation, but overrides and specific use cases
  might require additional accessibility considerations.
</details>
