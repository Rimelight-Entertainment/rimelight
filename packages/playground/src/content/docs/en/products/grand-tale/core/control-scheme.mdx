## Overview

Grand Tale operates under a strict hotkey / keybinding system.

<RLAAlert color="primary" variant="soft">
  Some of these bindings might not be 'traditional' (i.e.: "Inventory" on "I") or what players might
  expect. However, due to how large and complex of a game Grand Tale is, some on the proposal of new
  standards.
</RLAAlert>

## Gamepad

Grand Tale features full native gamepad support.

### Interaction & Navigation

General interaction and UI navigation across all platforms.

| Name        | Default Button |
| ----------- | -------------- |
| Interaction | `A`            |
| Menu        | `Menu`         |
| View / Map  | `View`         |
| Movement    | `Left Stick`   |
| Camera      | `Right Stick`  |
