The Grid component arranges child components in a responsive grid layout.

## Usage

Use the `cols` prop to specify the number of grid columns.

<ComponentShowcase>
  <RLAGrid cols={3}>
    <RLACard title="Item 1" description="Grid item 1" />
    <RLACard title="Item 2" description="Grid item 2" />
    <RLACard title="Item 3" description="Grid item 3" />
  </RLAGrid>

  <div slot="code-astro">
    ```astro
    ---
    import RLAGrid from "@rimelight/ui/components/grid/RLAGrid.astro";
    import RLACard from "@rimelight/ui/components/card/RLACard.astro";
    ---

    <RLAGrid cols={3}>
      <RLACard title="Item 1" description="Grid item 1" />
      <RLACard title="Item 2" description="Grid item 2" />
      <RLACard title="Item 3" description="Grid item 3" />
    </RLAGrid>
    ```

  </div>
</ComponentShowcase>
