A Dropdown Menu component that displays a list of choices or actions when toggled.

## Usage

How to use the Dropdown Menu component.

<ComponentShowcase>
  <RLADropdownMenu
    label="Options"
    items={[
      { label: "Profile", shortcut: "⇧⌘P", icon: "i-lucide-user" },
      { label: "Settings", shortcut: "⌘S", icon: "i-lucide-settings" },
      { type: "separator" },
      { label: "Logout", shortcut: "⌥⌘Q", icon: "i-lucide-log-out" }
    ]}
  />

  <div slot="code-astro">
    ```astro
    ---
    import RLADropdownMenu from "@rimelight/ui/components/dropdown-menu/RLADropdownMenu.astro";

    const items = [
      { label: "Profile", shortcut: "⇧⌘P", icon: "i-lucide-user" },
      { label: "Settings", shortcut: "⌘S", icon: "i-lucide-settings" },
      { type: "separator" },
      { label: "Logout", shortcut: "⌥⌘Q", icon: "i-lucide-log-out" }
    ];
    ---

    <RLADropdownMenu label="Options" items={items} />
    ```

  </div>
</ComponentShowcase>

## Examples

### Size

Use the `size` prop to change the size of the trigger and items. Supported values are `"sm"`, `"md"`, and `"lg"`.

<ComponentShowcase>
  <div class="flex items-center gap-4">
    <RLADropdownMenu
      label="Small Menu"
      size="sm"
      items={[
        { label: "View Info" },
        { label: "Edit Details" }
      ]}
    />
    <RLADropdownMenu
      label="Large Menu"
      size="lg"
      items={[
        { label: "View Info" },
        { label: "Edit Details" }
      ]}
    />
  </div>

  <div slot="code-astro">
    ```astro
    ---
    import RLADropdownMenu from "@rimelight/ui/components/dropdown-menu/RLADropdownMenu.astro";

    const items = [
      { label: "View Info" },
      { label: "Edit Details" }
    ];
    ---

    <RLADropdownMenu label="Small Menu" size="sm" items={items} />
    <RLADropdownMenu label="Large Menu" size="lg" items={items} />
    ```

  </div>
</ComponentShowcase>

### Custom Trigger Slot

You can override the trigger element entirely using the `trigger` slot.

<ComponentShowcase>
  <RLADropdownMenu
    items={[
      { label: "Profile" },
      { label: "Settings" }
    ]}
  >
    <button slot="trigger" class="flex items-center gap-1 px-3 py-1.5 bg-neutral text-neutral-foreground rounded-full text-sm">
      <span class="i-lucide-user size-4" />
      <span>My Account</span>
    </button>
  </RLADropdownMenu>

  <div slot="code-astro">
    ```astro
    ---
    import RLADropdownMenu from "@rimelight/ui/components/dropdown-menu/RLADropdownMenu.astro";

    const items = [
      { label: "Profile" },
      { label: "Settings" }
    ];
    ---

    <RLADropdownMenu items={items}>
      <button slot="trigger" class="flex items-center gap-1 px-3 py-1.5 bg-neutral text-neutral-foreground rounded-full text-sm">
        <span class="i-lucide-user size-4" />
        <span>My Account</span>
      </button>
    </RLADropdownMenu>
    ```

  </div>
</ComponentShowcase>
