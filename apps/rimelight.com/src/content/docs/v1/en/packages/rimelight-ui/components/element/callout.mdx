The `RLACallout` component provides a flexible callout/alert message box featuring icons, custom headers, body content, custom avatars, and actionable buttons.

## Usage

<ComponentShowcase>
  <RLACallout title="Information" description="This is a simple callout message." />

  <div slot="code-astro">
    ```astro
    ---
    import RLACallout from "@rimelight/ui/components/callout/RLACallout.astro";
    ---

    <RLACallout title="Information" description="This is a simple callout message." />
    ```

  </div>
</ComponentShowcase>

## Examples

### Variants & Colors

You can customize the `variant` ("solid", "outline", "soft", "subtle") and `color` ("primary", "success", "warning", "error", "neutral", etc.) of the callout:

<ComponentShowcase>
  <div class="flex flex-col gap-4 w-full">
    <RLACallout variant="soft" color="warning" title="Warning" description="This is a soft warning callout." />
    <RLACallout variant="outline" color="error" title="Error" description="An error occurred during operation." />
  </div>

  <div slot="code-astro">
  ```astro
  <RLACallout variant="soft" color="warning" title="Warning" description="This is a soft warning callout." />
  <RLACallout variant="outline" color="error" title="Error" description="An error occurred during operation." />
  ```
  </div>
</ComponentShowcase>

### Custom Icons & Slots

Use custom icons or slots like `icon`, `avatar`, `actions`, and `close`:

<ComponentShowcase>
  <RLACallout icon="i-lucide-info" title="Note" description="You can use custom slot-specific icons.">
    <div slot="actions">
      <button class="px-3 py-1 bg-primary text-white rounded text-sm">Action</button>
    </div>
  </RLACallout>

  <div slot="code-astro">
  ```astro
  <RLACallout icon="i-lucide-info" title="Note" description="You can use custom slot-specific icons.">
    <div slot="actions">
      <button class="px-3 py-1 bg-primary text-white rounded text-sm">Action</button>
    </div>
  </RLACallout>
  ```
  </div>
</ComponentShowcase>
