A small dot or counter that overlays a target element to indicate status, notifications, or counts. Can also be used `standalone` without wrapping any content.

## Usage

<ComponentShowcase>
  <RLAChip text="99+" standalone />

  <div slot="code-astro">
    ```astro
    ---
    import RLAChip from "@rimelight/ui/components/chip/RLAChip.astro";
    ---

    <RLAChip text="99+" standalone />
    ```

  </div>
</ComponentShowcase>

## Examples

### Colors

Use the `color` prop to change the color of the chip indicator.

<ComponentShowcase
  togglingPattern="tab-segmented"
  componentName="RLAChip"
  propsConfig={{
    color: ["primary", "secondary", "info", "success", "warning", "error", "neutral"]
  }}
  defaultProps={{
    color: "primary"
  }}
>
  <RLAChip text="5" standalone />
</ComponentShowcase>

### Sizes

Use the `size` prop to control how large the chip indicator appears.

<ComponentShowcase
  togglingPattern="tab-segmented"
  componentName="RLAChip"
  propsConfig={{
    size: ["xs", "sm", "md", "lg", "xl"]
  }}
  defaultProps={{
    size: "md"
  }}
>
  <RLAChip text="3" standalone />
</ComponentShowcase>

### Attached to an Element

Wrap any element with `RLAChip` to position the indicator relative to it.

<ComponentShowcase>
  <div class="flex items-center gap-6">
    <RLAChip text="5" position="top-right">
      <div class="w-10 h-10 rounded-full bg-muted flex items-center justify-center text-sm font-medium">A</div>
    </RLAChip>
    <RLAChip text="2" position="bottom-right" color="success">
      <div class="w-10 h-10 rounded-full bg-muted flex items-center justify-center text-sm font-medium">B</div>
    </RLAChip>
    <RLAChip text="9" position="top-left" color="warning">
      <div class="w-10 h-10 rounded-full bg-muted flex items-center justify-center text-sm font-medium">C</div>
    </RLAChip>
    <RLAChip position="bottom-left" color="error" inset>
      <div class="w-10 h-10 rounded-full bg-muted flex items-center justify-center text-sm font-medium">D</div>
    </RLAChip>
  </div>

<div slot="code-astro">
  ```astro

  <RLAChip position="bottom-left" color="error" inset>
  ```

</ComponentShowcase>

### Positions

Use the `position` prop to control where the chip is anchored relative to its wrapped content.

<ComponentShowcase
  togglingPattern="tab-segmented"
  componentName="RLAChip"
  propsConfig={{
    position: ["top-right", "top-left", "bottom-right", "bottom-left"]
  }}
  defaultProps={{
    position: "top-right"
  }}
>
  <RLAChip text="•">
    <div class="w-10 h-10 rounded-full bg-muted flex items-center justify-center text-sm font-medium">
      U
    </div>
  </RLAChip>
</ComponentShowcase>

### Inset

Set `inset` to overlap the chip inside the element's border instead of extending beyond it.

<ComponentShowcase>
  <div class="flex items-center gap-6">
    <RLAChip text="3" position="top-right">
      <div class="w-10 h-10 rounded-full bg-muted flex items-center justify-center text-sm font-medium">Default</div>
    </RLAChip>
    <RLAChip text="3" position="top-right" inset>
      <div class="w-10 h-10 rounded-full bg-muted flex items-center justify-center text-sm font-medium">Inset</div>
    </RLAChip>
  </div>

<div slot="code-astro">
  ```astro
  <RLAChip text="3" position="top-right">
    <div>Default</div>
  </RLAChip>
  <RLAChip text="3" position="top-right" inset>
    <div>Inset</div>
  </RLAChip>
  ```
</div>
</ComponentShowcase>

### Show / Hide

Use `show` to programmatically toggle chip visibility without removing it from the DOM.

<ComponentShowcase>
  <div class="flex items-center gap-6">
    <RLAChip text="5" show>
      <div class="w-10 h-10 rounded-full bg-muted flex items-center justify-center text-sm font-medium">On</div>
    </RLAChip>
    <RLAChip text="5" show={false}>
      <div class="w-10 h-10 rounded-full bg-muted flex items-center justify-center text-sm font-medium">Off</div>
    </RLAChip>
  </div>

<div slot="code-astro">
  ```astro
  <RLAChip text="5" show>
    <div>On</div>
  </RLAChip>
  <RLAChip text="5" show={false}>
    <div>Off</div>
  </RLAChip>
  ```
</div>
</ComponentShowcase>
