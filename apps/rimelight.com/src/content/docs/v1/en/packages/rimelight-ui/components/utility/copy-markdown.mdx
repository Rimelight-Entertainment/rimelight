The Copy Markdown component provides a button that copies a raw markdown string directly to the user's clipboard.

## Usage

Pass a `raw` prop containing the markdown content to copy.

<ComponentShowcase>
  <RLACopyMarkdown raw="# Hello Rimelight\nThis is raw markdown content." />

  <div slot="code-astro">
    ```astro
    ---
    import RLACopyMarkdown from "@rimelight/ui/components/copy-markdown/RLACopyMarkdown.astro";
    ---

    <RLACopyMarkdown raw="# Hello Rimelight\nThis is raw markdown content." />
    ```

  </div>
</ComponentShowcase>
