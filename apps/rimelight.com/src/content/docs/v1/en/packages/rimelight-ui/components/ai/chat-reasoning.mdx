The ChatReasoning component formats and manages the styling for showing step-by-step thinking processes of modern large language models.

## Usage

Use the ChatReasoning component within a message bubble to isolate chain-of-thought explanations.

<ComponentShowcase>
  <RLAChatReasoning class="border-l-2 border-primary/30 pl-4 py-2 my-2 text-xs text-muted-foreground flex flex-col gap-2">
    <div class="font-medium text-muted">Thinking Process:</div>
    <p>1. Analyze user request to update MDX documentation.</p>
    <p>2. Review RLA component structure and matching props config.</p>
    <p>3. Generate clean Astro layout showcase snippets.</p>
  </RLAChatReasoning>
