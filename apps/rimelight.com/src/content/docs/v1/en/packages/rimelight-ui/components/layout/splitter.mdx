A Splitter component allows you to divide a container into multiple resizable areas. Users can drag the splitter handles to resize the panels.

## Usage

How to use the Splitter component in its simplest form.

<ComponentShowcase>
  <RLASplitter class="h-64 border border-border rounded-md overflow-hidden">
    <div class="flex items-center justify-center h-full bg-neutral-100 dark:bg-neutral-800">Left Content</div>
    <div slot="panel" class="flex items-center justify-center h-full bg-neutral-200 dark:bg-neutral-700">Right Content</div>
  </RLASplitter>

  <div slot="code-astro">
    ```astro
    ---
    import RLASplitter from "@rimelight/ui/components/splitter/RLASplitter.astro";
    ---

    <RLASplitter class="h-64 border border-border rounded-md overflow-hidden">
      <div class="flex items-center justify-center h-full bg-neutral-100 dark:bg-neutral-800">
        Left Content
      </div>
      <div slot="panel" class="flex items-center justify-center h-full bg-neutral-200 dark:bg-neutral-700">
        Right Content
      </div>
    </RLASplitter>
    ```

  </div>
</ComponentShowcase>

## Examples

### Vertical Direction

Use the `direction="vertical"` prop to split panels vertically.

<ComponentShowcase>
  <RLASplitter direction="vertical" class="h-64 border border-border rounded-md overflow-hidden">
    <div class="flex items-center justify-center h-full bg-neutral-100 dark:bg-neutral-800">Top Content</div>
    <div slot="panel" class="flex items-center justify-center h-full bg-neutral-200 dark:bg-neutral-700">Bottom Content</div>
  </RLASplitter>

  <div slot="code-astro">

    import RLASplitter from "@rimelight/ui/components/splitter/RLASplitter.astro";

### Custom Sizes

Set the initial panel sizes as percentages using the `defaultSizes` prop.

<ComponentShowcase>
  <RLASplitter defaultSizes={[30, 70]} class="h-64 border border-border rounded-md overflow-hidden">
    <div class="flex items-center justify-center h-full bg-neutral-100 dark:bg-neutral-800">30% Width Panel</div>
    <div slot="panel" class="flex items-center justify-center h-full bg-neutral-200 dark:bg-neutral-700">70% Width Panel</div>
  </RLASplitter>

  <div slot="code-astro">
    ```astro
    ---
    import RLASplitter from "@rimelight/ui/components/splitter/RLASplitter.astro";
    ---

    <RLASplitter defaultSizes={[30, 70]} class="h-64 border border-border rounded-md overflow-hidden">
      <div class="flex items-center justify-center h-full bg-neutral-100 dark:bg-neutral-800">
        30% Width Panel
      </div>
      <div slot="panel" class="flex items-center justify-center h-full bg-neutral-200 dark:bg-neutral-700">
        70% Width Panel
      </div>
    </RLASplitter>
    ```

  </div>
</ComponentShowcase>
